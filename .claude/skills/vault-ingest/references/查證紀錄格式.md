# 查證紀錄格式

claude-research 草稿寫進 raw 前，主對話抽查。沒有查證紀錄段的 claude-research 卡不寫入。
這一步在防：子代理經摘要工具取得的句子被當成原文引用，錯誤數字一路進到參考模型卡。

## 一、抽查

| 項 | 做法 |
|----|------|
| 抽哪些 | 每個來源網址至少一條；標「摘要工具，未逐字核對」的結論優先；含數字、版本、模型名的句子優先 |
| 比對方式 | 主對話自己讀原頁面，逐字比對原文句、數字、名稱 |
| 結果 | 相符、更正、查無三選一 |
| 更正 | 直接改草稿該句；紀錄寫改前與改後 |
| 查無 | 刪該條，或移到無法確認處 |

## 二、段落格式

寫在原始素材段之後、第一輪初步分析段之前。

```markdown
## 查證紀錄（主對話抽查）

| 來源 | 抽查方式 | 結果 |
|------|---------|------|
| <網址或來源編號> | 逐句比對 N 組關鍵句、數字 | 全部相符；或：一處更正，<改前> 改為 <改後> |

未抽查：<來源清單>。這些引文採用時標「未逐字核對」。
```

範例：[[2026-10-29-claude-research-claude.dev對Claude5世代的使用建議]] 的查證紀錄段。
