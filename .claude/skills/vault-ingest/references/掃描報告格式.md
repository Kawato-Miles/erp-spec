# 掃描報告格式（mode C）

只讀 `memory/Sens_wiki/raw/`，不動檔。本檔是 vault-ingest 門檻值的唯一出處。

## 一、門檻

| 門檻 | 值 | 到門檻時 |
|------|----|---------|
| status=raw 累積張數 | 10 張 | 建議跑 mode C |
| 同主題（topic-tag）的 status=raw 卡 | 3 張 | 建議跑 mode B，一併判合併去處 |
| status=raw 停留天數 | 30 天 | 建議精練，或改 cancelled |
| status=reviewed 停留天數 | 5 天 | 提醒 Miles 確認 |

## 二、報告

| 段 | 寫法 |
|----|------|
| 待處理（status=raw） | 依 source 分組、created-at 排序；欄位：檔名、source、created-at、停留天數 |
| 處理中（status=reviewed） | 同上 |
| 已精練（status=ingested） | 檔名、ingested-at、ingested-to |
| 警示 | 同主題累積、停留超期、claude-research 缺 raw-source-link 或查證紀錄段、miles-upload 缺 attached-files、ingested-to 指向已不存在的卡 |

log 一筆：

```markdown
## [YYYY-MM-DD HH:MM] 納入(ingest-C) | raw 掃描
- 變更：待處理 N 張、處理中 M 張；警示 <項目或無>
- 動機：免（健檢類）
- 衝突：無
```
