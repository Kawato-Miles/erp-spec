# 範本 - Linear 交付

交付的段落骨架。複製後替換 `<...>` 占位。本檔的內層程式碼區塊前加了零寬字元，避免中斷外層區塊；貼進 Linear 前移除，否則狀態圖無法渲染。本檔只放結構；每段怎麼寫依 `規範 - Linear 交付.md`，合規樣貌見 `範例 - Linear 交付.md`。
