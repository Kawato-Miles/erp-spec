# 誤判要素

Miles 指出稽核誤判時讀本檔。適用對象：erp-audit 的稽核者、推演者、懷疑者，以及 vault-audit 的稽核者。正本卡：[[稽核誤判記錄]]（`../../../../memory/Sens_wiki/wiki/erp/11-review-knowledge/稽核誤判記錄.md`）。

## 一、算不算誤判

| 判斷 | 情況 |
|------|------|
| 算 | 假缺漏、分級判錯、規則套錯、命名誤判，且 Miles 已確認 |
| 不算 | 一般 spec 修訂建議；稽核建議合理但 Miles 不採（設計選擇）；純口語措辭調整 |
| 先問 Miles | 未確認的「可能誤判」 |

識別到誤判就建檔。不接受只口頭說「下次注意」。

## 二、順序

| 步 | 動作 |
|----|------|
| 1 | 提取要素（§ 三） |
| 2 | 去重（§ 四） |
| 3 | 把分類與建議動作呈給 Miles |
| 4 | Miles 確認後追加 |
| 5 | 回寫（§ 六） |
| 6 | 更新卡的 frontmatter `last-reviewed` 為當天 |
| 7 | 回報：分類、案例標題、教訓一句、回寫了哪幾處 |

## 三、要素

| 要素 | 寫法 |
|------|------|
| 日期與場景 | 哪個規劃主題、第幾輪、哪個檢核項或稽核維度 |
| 誤判內容 | 稽核者判了什麼 |
| Miles 指正 | 原話保留，不轉述 |
| 實際情況 | 引卡名與原文行號 |
| 教訓 | 寫具體場景，下次稽核套得回去；不用學術詞 |
| 修正後判準 | 回寫到哪一處 |
