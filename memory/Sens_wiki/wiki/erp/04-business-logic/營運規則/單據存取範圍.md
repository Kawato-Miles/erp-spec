讀完這張卡，你會知道：

- 說出單據存取範圍有哪些用詞，各指哪些單據
- 判斷某個角色打開某個模組，看得到哪些單據
- 分辨管理權責（誰對單據負責）與操作權限（誰在系統上能動單據）
- 找到各模組哪些角色看全公司
- 知道為什麼範圍只管看得到哪些單，動作另列

## 現況

後端只有訂單與需求單依單據範圍判定，工單與生產管理尚未依範圍判定。

## 規則

### 範圍用詞

| 用詞 | 定義 |
|------|------|
| 全公司 | 該模組全部單據 |
| 自己負責 | 該單據的負責欄位是本人（各單據看哪一欄見下表） |
| 被分享（檢視） | 以檢視層級分享給本人且未撤銷的單據 |
| 被分享（編輯） | 以編輯層級分享給本人且未撤銷的單據 |
| 所屬產線 | 單據的產線在本人的所屬產線內。只用於生產相關模組。所屬產線欄見 [[人員]] |

### 各單據看哪一欄

| 單據 | 「自己負責」看的欄位 |
|------|---------------------|
| 需求單 | 接單業務；建立者只留紀錄，不構成自己負責 |
| 訂單 | 接單業務；訂單無建立者途徑 |
| 諮詢單 | 諮詢人員 |
| 工單 | 負責人 |
| 審稿（印件） | 負責審稿人員 |
| 派單 | 指派供應商 |
| 生產任務、工作包 | 指派師傅 |
| 轉交單 | 負責廠務 |

### 上下層延伸

- 上層單據的自己負責者與被分享者，也看得到下層單據。
- 持有上層全公司範圍的角色，不因此延伸到其他模組的下層單據。
- 其他模組指出貨單、工單、審稿、品檢紀錄、品檢待驗清單。
- 其他模組也指售後服務單。
- 其他模組也指待開發票、待退款、帳務異常清單。
- 其他模組也指應收款項清單。
- 旗下印件、訂單異動、收款項目、發票、款項紀錄屬訂單模組本身，範圍與訂單相同。
- 被分享延伸時，層級沿用上層。
- 看哪個模組，就用哪個模組的範圍。

| 上層 | 下層 |
|------|------|
| 訂單 | 款項跨訂單清單中屬於該訂單的項目 |
| 訂單 | 審稿模組中屬於該訂單的印件 |
| 訂單 | 出貨單 |
| 訂單 | 品檢紀錄 |
| 訂單 | 工單 |
| 訂單 | 售後服務單 |
| 工單 | 品檢待驗清單與品檢紀錄中屬於該工單的印件 |
| 工單 | 工單詳情內的生產任務（生產管理模組仍依所屬產線） |

### 分享

- 需求單、訂單、工單有分享成員。
- 被分享（檢視）與被分享（編輯）對所有角色一律適用。
- 兩種分享層級各能做什麼，正本在 [[單據分享與職務代理]]。
- 分享的授予、存取與收回過程見 [[單據分享與職務代理]]。
- 需求單的評估印務主管，由系統自動取得被分享（編輯）。
- 規則見 [[需求單]] 評估印務主管欄。
- 「被指派」不是獨立用詞。

### 管理權責與操作權限

- 管理權責是誰對單據負責，例如需求單與訂單由接單業務負責。
- 操作權限是誰在系統上能動某張單，由動作規則決定。
- 管理權責仍在負責人。
- 編輯層級的分享成員動了單據，也是如此。
- 系統自動授予的人動了單據，也是如此。

## 為什麼這樣定

### 範圍用詞

用詞固定，交付開發的權限表才能照抄，後端也能照用詞切權限。所屬產線只用在生產相關模組。訂單與需求單的單據沒有產線歸屬。

### 各單據看哪一欄

每種單據的負責欄位不同。逐單據寫明看哪一欄，同一個用詞才不會在不同模組指向不同的人。

### 上下層延伸

不必每多一種上下層關係，就多一個範圍用詞。上層單據看得到，下層單據就跟著看得到。代理與交接才做得完。

### 分享

分享不看角色，是因為代理與交接要走得完。不能卡在被分享的人沒有對應角色。系統自動授予，業務就不必每次手動授權。

### 各模組持有全公司範圍的角色

角色看得到全部單據、卻只做特定動作，很常見。範圍只回答看得到哪些單。動作另列，兩件事才不會綁在一起。

### 管理權責與操作權限

兩者分開寫，因為能動單據的人，不一定是負責的人。責任留在負責人，追溯時才找得到該回答的人。

## 範圍外

- 權限項目怎麼切、叫什麼名字，歸後端；wiki 不寫權限名稱。
- 每個動作誰能在哪個範圍做 → 正本在各動作所屬的規則卡、角色卡與實體卡。
- 本卡只定範圍用詞與可見範圍。
- 欄位或頁籤層級的可見性：看得到單據，但某欄或某頁籤遮住。去處見 [[XM-016-詳情頁頁籤與欄位層級的可見性規則]]。
- 因下層單據而看見上層單據：去處見 [[XM-016-詳情頁頁籤與欄位層級的可見性規則]]。
- 會計的派單成本檢視：去處見 [[XM-017-會計檢視派單成本的範圍]]。
- 各生產管理單元列哪些單據與操作 → 正本在 [[印件生產流程]] § 生產管理單元的權限範圍
- 分享的授予、存取、收回過程 → 正本在 [[單據分享與職務代理]]
- 改派負責人 → 正本在 [[訂單接單業務改派]] 與各單據的改派規則
- 列表預設只列自己負責或被分享的工單。這屬介面預設篩選，正本在 Prototype。
- 角色與權限的對應，屬後端角色設定。
