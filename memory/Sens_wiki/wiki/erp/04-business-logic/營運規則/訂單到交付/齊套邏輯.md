## 現況

目前判斷「印件做完了沒」靠人工口頭回報，無法即時追蹤各工序進度。當某道工序卡住時，業務與客戶都無法判斷真實的可出貨數量。

## 規則

一個印件可能需要多道工序（如印刷 + 裝訂 + 裁切），每道工序各自有進度。印件的整體完成數量以進度最慢的工序為準——任何一道工序沒做完，印件就不算完成、不能出貨。

各工序的完成數量以產出數量為準——即報工的良品數加不良品數，投入端的生產數量與放損不計入完成度（工序之間不設品檢節點）。印件的可出貨數量以入庫前**最終品檢**的通過數量為準（未通過不計入）；品檢以印件層的 [[品檢紀錄]] 承載——品檢人員依到貨分次驗、一次驗收一筆，累計通過即入庫（品檢型生產任務廢止）。

## 數量帳與額度公式（正本）

> 本段是入庫量、可出貨額度、轉交可申請上限的公式唯一正本；[[出貨單狀態]]、[[轉交單狀態]]、[[出貨單]]、[[印件]] 各卡引用此處、不複寫。

印件的數量帳統一為**九個數量**（本表為清單與定義的唯一正本，[[2026-06-13-生產模組架構設計]] 與各實體卡引用不重述）：

| 數量 | 定義 | 層級與來源 |
|------|------|-----------|
| 目標數量 | 訂單要的數量（生產端含加放由印務決定） | 印件層；工單／生產任務層各有目標數量、經倍數換算（[[數量換算規則]]） |
| 預計生產數 | 目標數量加各工序放損累積換算後、實際要投入的量（推導值非輸入欄位） | 印件層；換算規則見 [[數量換算規則]]（放損兩成分見 [[工序主檔]]／[[設備]]） |
| 生產數量 | 報工累計的**投入**量（含最終沒變成成品的放損） | 工單／生產任務層，[[報工紀錄]] 累計 |
| 產出數量 | 報工累計的**產出**量＝良品數＋不良品數（完成度與齊套判定取此數） | 工單／生產任務層，[[報工紀錄]] 累計 |
| 良品數／不良品數 | 師傅報工時分開填報的兩個數，產出數量的組成 | 印件層衍生自報工紀錄 |
| 放損 | 生產數量 −（良品數＋不良品數），系統推算不由人填 | 生產任務層，[[報工紀錄]] 唯讀欄 |
| 不良品處置數 | 品檢缺口的處置分流帳：補做／客戶照收／報廢——**報廢數落於此**，是折損率分子的來源 | 印件層；處置由印務決策（[[QC不通過補生產]]） |
| 完工良品數 | 品檢通過累計（[[品檢紀錄]]） | 印件層；**品質帳唯一的家**，工單層不設此欄、工單頁不顯示品檢進度 |
| 入庫數 | **現階段＝完工良品數（同一個數）**；[[成品庫存]] 啟用後才分離為實際進倉數，帳的算法屆時不變 | 印件層 |
| 出貨數 | 已出貨數與累計送達數 | 印件層，出貨明細行加總（SHP-009 決議） |

通過側守恆鏈：**產出數量 ≥ 良品數 ≥ 品檢通過累計（＝入庫數）≥ 已出貨數 ≥ 累計送達數**。缺口側（報工不良品數與品檢不通過數的關係與去重口徑）不在本卡定死，掛 [[QC-004-報工不良與品檢缺口取數口徑]]；材料用量的帳不在本卡範圍（歸屬見 [[PT-023-材料用量帳與放損換算鏈正本歸屬]] 與 [[物料消耗記錄]]）。

- **齊套完成數**（印件層）＝各計入工序的產出數量取最慢者（不影響成品的工序排除），供進度追蹤參考
- **入庫數**（印件層，Phase 1）＝[[品檢紀錄]] 通過數量的累計（＝完工良品數）。分次驗收逐筆累計、額度隨之逐批放大。無成品庫存實體——入庫的語意是「完成品檢、可出貨」（[[成品庫存]] 實體保留 Phase 2/3）
- **多工單印件**不需另設取小規則：送驗的是工序依賴圖終點的完成品（各工單的工序天然已齊備），品檢在印件層驗、入庫數直接記印件（隨品檢模型改掛印件層收斂；工序層的取慢邏輯仍在齊套完成數）
- **可出貨額度**（印件層）＝入庫數 − 已出貨數 ＋ 出貨單回補。**已作廢與異常皆自動回補**（見 [[SHP-010-異常出貨單可出貨額度是否回補]] 決議）：拒收退件轉「異常」即回補、業務建新單重出；實物由揀貨與出貨作業把關，貨遺失時業務不建新單即可，退回貨不設系統強制重驗。**退回實物不進系統流程**（不走 [[轉交單]] 留痕、不設入區登記），場內由現場人工處理；要重新出貨就開新出貨單、原出貨單收於異常或作廢兩終態之一，重出前是否重驗與退回貨是否報廢皆由 [[印務]] 個案判斷（見 [[SHP-014-出貨異常退回實物場內去向與留痕]] 決議）
- **轉交可申請上限**（生產任務層）＝該生產任務產出數量 − 已被轉交明細抽走數 ＋ 轉交作廢回補

**工單完成判定**＝旗下生產任務全部完成（含補做任務）。工單管製作帳、品質與可出貨帳歸印件層品檢紀錄，兩本帳脫鉤；補做經工單異動加開生產任務時工單自然重開，補做完成後再次完成。

**短出（讓步允收）收尾**：客戶同意少收時，由 [[印務]] 在印件層手動結案（印製維度轉「已送達」，轉換與動機見 [[印件狀態]]），**購買數量與已出貨數量都原樣保留、不下修**——原本訂多少、實際出多少要事後查得出來。結案由上而下批次連動：旗下未完成工單推「已完成」、其下生產任務一併推完成。**要不要退款是獨立維度**——可能少出但不退（雙方談定）；要退則由 [[業務]] 開一張退款訂單異動：送 [[業務主管]] 核可（只裁能不能退、應收此刻不動），與客戶談定金額後執行「確認生效」，應收於此刻下降、認列（見 [[訂單異動規則]]）。訂單完成後同樣是這張退款訂單異動，只是改開在 [[售後服務]] 單底下。短出不下修數量、應收沒降，退款與數量拆開走。訂單異動加量已拍板為加開新印件（[[PT-009-生產數量追加調整與工單異動承接]]），原印件數量鎖定不位移，明細金額時點見 [[明細時點分界]]。

**打樣週期歸零特例**：打樣印件因 NG-製程問題重打時，舊週期樣品報廢——自入庫數與累計送達數移出、六個數量按打樣週期歸零重算（報廢量計入成本），第二輪自新打樣工單起重新累計；否則舊樣計入累計會使「累計送達＝印件數量」永遠湊不齊。歸零是「全數補做」的自然帳務結果，留底為印件上的「打樣結果」欄位值與新打樣工單本身（不另開單據，見 [[打樣流程]]）；回頭轉換見 [[印件狀態]]。

## 為什麼這樣定

印刷品是由多道加工組合而成的成品。如果只看單一工序的完成數就出貨，客戶會收到不完整的半成品（例如印好但沒裝訂的書）。以最慢工序為準，確保出貨的都是完成品。

## 領域知識

- 印刷品常需多道加工（印刷 → 上光 → 裁切 → 裝訂），每道可能在不同工廠
- 某些工序不影響成品（如包裝），完成度計算可排除
- 成品數量與各工序所需數量之間有倍數關係（如 1 本書 = 16 張台紙），系統需自動換算（詳見 [[數量換算規則]]）

## 具體例子

例子 1：某客戶訂 1000 本型錄，需要印刷 + 裝訂兩道工序。印刷完成 1000 份，但裝訂只完成 600 份。可出貨數量 = 600（以裝訂為準），不是 1000。

例子 2：某印件需要印刷 + 上光 + 裁切三道工序。印刷完成 500、上光完成 500、裁切完成 480。可出貨數量 = 480（以裁切為準）。其中上光如果標記為「不影響成品」，則只看印刷與裁切，可出貨 = 480。

## 例外情境

- 若印件只有一道工序，不存在齊套問題，完成數就是該工序的完成數
- 標記為「不影響成品」的工序不計入齊套計算
