讀完這張卡，你會知道：

- 知道前置到料多少才可以報工
- 說出前置到料量為 0 時系統怎麼處理
- 知道派工會不會檢查前置到料
- 說出為什麼這樣定

## 規則

| 種類 | 意圖 |
|------|------|
| 做法 | 分批流動是常態不是破例 |

前置到料量大於 0 即可報工、到多少做多少（可做量＝讓 [[供需不等式（需轉交）]] 與 [[供需不等式（不需轉交）]] 對每個前置都仍成立的最大 B.生產數量）；前置到料量為 0 時系統擋下報工並指出在等哪張工單、哪一筆生產任務的貨；派工不檢查前置到料

## 為什麼這樣定

工序常跨天分批完成，做完的部分先流到下一站；把關擺在派工只會把每一次派工都擋掉，師傅動手前才是「貨到了沒」真正有答案的時點

## 適用範圍

- [[生產流程群組]] 階段 5（製作與報工）— 前置到料量為 0 時擋下報工

## 具體例子

- 例子 1（並行匯流）：專輯袖套案，封面與內頁各自印刷加工，印務把裝訂任務的前置設為封面加工＋內頁加工——封面到料 300、內頁到料 200，裝訂可做量＝200；內頁到料 0 時裝訂報不了工。
- 例子 2（滾動累積）：貼紙 1000 張，印刷每天報工良品 200、裁切為下一道（預設需轉交）。裁切到料量隨每天的點收滾動累加——第一天到料 200、可做 200，到印刷第五天全部完成時裁切已累積可做 800，不必空等最後一批。搬運那一段的完成過程見 [[場內轉交與修正]]。
