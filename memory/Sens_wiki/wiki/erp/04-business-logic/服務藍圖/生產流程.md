讀完這張卡，你會知道：

- 說出從工單變成可出貨成品的這段服務在做什麼、客戶最後拿到的是什麼
- 知道這段流程從印件已確認可製作之後接手、到裝箱完成交給出貨段為止
- 說出八個階段的順序、每階段誰負責、交接給誰
- 分辨現場的事實由哪五種角色回報、各自記在哪張單據
- 判斷哪些規則在哪個階段生效

## 流程階段

角色分工（印務工作模式 SOP 的核心邏輯）：

| 層 | 角色 | 負責什麼 |
|----|------|---------|
| 需求 | 前端 | 提出報價單 |
| 翻譯 | [[印務]] | 報價單轉工單、定義產線與品檢執行標準 |
| 派工與流動 | [[生管]]／[[廠務]] | 生管定誰做何時做、廠務定東西怎麼到 |
| 製作 | 產線（[[師傅]]）| 報工並附現場照片 |
| 檢查 | [[品檢人員]] | 照工單驗，只回報不決策 |
| 裝箱 | [[揀貨人員]] | 依出貨單打包、回報裝箱內容 |
| 對外物流 | [[出貨人員]] | 交寄第三方物流並確認送達 |

現場的事實由執行者本人回報，共五種，各有既定載體：

| 階段 | 角色 | 回報內容 | 載體 |
|------|------|---------|------|
| 製作 | [[師傅]] | 報工（投入、良品數、不良品數、實際工時＋現場照片；材料型任務只填領用量、外發回廠只補記良品與不良品） | [[報工紀錄]]；報工的五個提交管道是本類回報的來源細分（見 [[報工規則]]） |
| 流轉 | [[生管]]／[[廠務]]／收貨人 | 生管建單決定送哪幾筆各送多少 → 廠務起搬 → 廠務卸貨送達＋現場照 → 目的地收貨人（[[師傅]] 或 [[品檢人員]]）點收 | [[轉交單]] |
| 品檢 | [[品檢人員]] | 品檢結果（通過數量＋照片），通過即入庫（可出貨） | [[品檢紀錄]]（印件層、紀錄型） |
| 揀貨 | [[揀貨人員]] | 裝箱內容（實際裝箱數量＋箱數＋箱規＋照片），回報動作推進出貨單狀態 | [[出貨單]]（回報直接記在出貨單上） |
| 出貨 | [[出貨人員]] | 第三方物流單與出貨執行 | [[出貨單]] |

### 1. 工單產生與分派

- 階段目標：每張要製作的印件都有工單，且每張工單有主責印務。
- 角色與交接：印件印製維度進入「製程已確認」時系統自動產生第一張草稿工單。進入該維度前有一道製作細節確認的前置，正本見 [[線下訂單流程]] 階段 7。要增加工單由 [[印務主管]] 自行加開，統一分派給 [[印務]]，分派後該工單主責移交印務。一張工單對應一位印務。詳見 [[工單狀態]]。
- 決策點：無。

### 2. 製程規劃（印務翻譯）

- 階段目標：把工單翻譯成產線做得動的製程，並定下最終品檢要照什麼驗。
- 角色與交接：印務在被分派的工單上，依 [[BOM結構]] 建立生產任務（材料／工序／裝訂）、填寫製程、規劃工序相依性（哪些要先做、哪些需轉交）、把品檢需求（重點檢查項目、客戶要求、可接受範圍）寫進工單供最終品檢依循，送印務主管製程審核。詳見 [[BOM結構]]、[[工序相依性規則]]。
- 決策點：無。

### 3. 派工（生管）

- 階段目標：生產任務落到具體師傅與機台上、可以開工。
- 角色與交接：製程審核完成、工單交付產線後，[[生管]] 把生產任務分派給師傅、與機台師傅溝通。詳見 [[生產任務狀態]]。
- 決策點：派工前系統檢查工序相依性前置（數量級：前置到料量大於 0 即可開工、到多少做多少，需轉交者看轉交已點收量），詳見 [[工序相依性規則]]。

### 4. 製作與報工（產線）

- 階段目標：做出實際數量並回報，讓進度向上反映到工單、印件、訂單。
- 角色與交接：師傅／供應商執行生產，從自己的介面報工；工序型任務填投入、良品數、不良品數與實際工時（放損由系統推算），材料型任務只填領用量，外發回廠由 [[印務]] 依點收結果只補記良品與不良品（欄位正本見 [[報工紀錄]]）。首次報工讓生產任務轉「製作中」並向上反映到工單、印件、訂單。各層被推動的前態條件由各自的狀態機卡承載，見 [[工單狀態]]、[[印件狀態]]、[[訂單狀態]]；補做期間上層已越過者不回頭。詳見 [[報工規則]]、[[生產任務狀態]]。
- 決策點：無。

### 5. 廠內外流轉（廠務）

- 階段目標：半成品在站與站、廠與廠之間流動到位，下游接得下去。
- 角色與交接：
  - 場內：段序之間由[[廠務]]運送印件；場內跨站移動以[[轉交單]]記錄——轉交為**滾動常態**：生產任務預設需轉交（印務只標例外「不需轉交」），師傅報工即累積可搬的良品量，[[生管]] 在待搬視圖建單（決定送哪幾筆、各送多少，可一次勾多筆按目的地分組成單）→ 廠務起搬 → 廠務卸貨送達附現場照 → 目的地收貨人點收（產線由該線 [[師傅]] 群、品檢站由 [[品檢人員]]），下游依**已點收量**滾動開工，詳見 [[工序相依性規則]]、[[轉交單]]。本階段的轉交只做產線 → 產線與生產任務 → 品檢站兩類路徑（後者的來源含場內產線上的任務與回台點收後的外發生產任務）。
  - 外發：外發加工（外包廠／中國廠）由印務負責，以[[派單]]承載外部委外進程（持[[派單狀態]]），中國回台物流與運費關稅見[[貨運單]]；外發在途粗狀態由 [[派單狀態]] 自動映射回生產任務，**回廠後由[[揀貨人員]]在暫存區做運單點收登記（清點＋秤重、不切狀態），[[印務]]依點收結果切派單「台灣已入庫」並對生產任務報工、達標轉已完成，生管建轉交單送下一產線（接力見 [[外發委外與回廠點收]]）**。
- 決策點：走哪一種完成路徑（完全廠內／廠內＋外發／完全外發）；外發走中國線或台灣外包——中國線與台灣外包流程一致，差別只在點收載體（中國線走 [[貨運單]] 明細、台灣外包直接對生產任務點收）。三種完成路徑與三實體分工詳見 [[印件生產流程]]。

### 6. 品檢（品檢人員）

- 階段目標：每張印件入庫前必經**最終品檢**（強制；可分次驗，每次記一筆品檢紀錄），確認通過數量；工序之間不設品檢節點。
- 角色與交接：品檢照工單驗、回報通過數量（文字＋照片），只回報不決策。品檢分次驗、隨驗隨入庫即常態，臨時分批出貨不需破例。詳見 [[工序相依性規則]]、[[品檢紀錄]]。
- 決策點：品檢缺口的處置為兩個獨立決策的組合——「缺口補不補」（補做，或短出結案）×「瑕疵品去向」（報廢，或客戶照收）。兩個決策由印務與業務討論，必要時業務向客戶確認；短出結案的執行者與收尾機制正本見 [[齊套邏輯]]。

### 7. 入庫（可出貨）

- 階段目標：品檢通過的數量計入印件完工良品數，取得可出貨額度。
- 角色與交接：入庫不是倉儲庫存管理——客製品按單生產，沒有做好等人買的成品倉（庫存概念保留給材料）；入庫的語意是「這張印件完成品檢、可以出貨」。品檢通過的貨留在品檢區等揀貨，品檢區即出貨（揀貨）區。
- 決策點：無；完工良品數決定可出貨額度，多工單印件不另設取小規則，計算正本見 [[齊套邏輯]]。

### 8. 揀貨（揀貨人員）

- 階段目標：依出貨單把成品清點裝箱，交給對外物流。
- 角色與交接：業務建立出貨單即揀貨指令（出貨明細可含同訂單多種印件合箱）。[[揀貨人員]]按「開始揀貨」、依單清點打包裝箱、在出貨單上回報裝箱內容（實際裝箱數量／箱數／每箱幾個／箱規／照片），完成後交出貨段，出貨單的狀態列舉與推進見 [[出貨單狀態]]。
- 決策點：無。
