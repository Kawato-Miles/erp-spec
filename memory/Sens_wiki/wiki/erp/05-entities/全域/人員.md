# 人員（User）

讀完這張卡，你會知道：

- 說出公司裡能登入系統的人為什麼要獨立成全公司共用的一份資料，不寫進各角色卡、也不隸屬任何業務單據
- 找到一個人身上業務看得到的每個欄位，說出能力等級由哪個操作設定
- 看懂停用一個人之後會連帶影響什麼、為什麼離職是停用而不刪帳號
- 分辨能力等級為什麼跟人綁在一起而不掛在角色上，以及沒設值代表什麼

## 營運背景

人員是什麼見 [[ERP 詞彙表#人員]]。一個人可能同時擔任多個角色（例如兼任審稿主管與審稿人員），停用一個人要一次讓他從所有派工與分派候選裡消失，所以這些設定必須掛在人身上、不能散在各角色卡。

能力等級（是什麼見 [[ERP 詞彙表#能力等級]]）是這裡唯一一個跟人綁在一起的業務能力設定，決定線上單自動分派會不會把印件派給他。
