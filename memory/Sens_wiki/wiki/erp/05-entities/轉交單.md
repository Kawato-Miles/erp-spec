# 轉交單（TransferTicket）

讀完這張卡，你會知道：

- 說出一張轉交單管多少範圍——綁單一印件、不跨印件，明細可含同印件跨工單的多筆生產任務
- 說出一張轉交單怎麼生出來——師傅報工累積出可轉交量、廠務挑貨搬運並確認送達即成單，印務只處理作廢與改路徑這類例外
- 分辨哪些搬運走轉交單、哪些不走（場內站間移動含暫存區進出走轉交，場外回場的物流不走）
- 找到一張轉交單上看得到的每個欄位、誰填、什麼時候寫入，以及一次最多能轉多少要查哪張卡
- 說出轉交跟下游能不能開工的關係（已送達數量就是下游的到料量），以及狀態名在哪張卡

## 營運背景

一張轉交單綁定**單一印件**（不跨印件），承載這次運送的對象、數量與送達憑證。同一印件可開多張轉交單（分批轉交，對應分批出貨）；一張轉交單的明細可含同印件、跨工單的多筆生產任務（例如印件 A 的工單 1 印刷＋工單 2 外包模切合併一趟送）。

這張單串聯上下兩個生產任務：上一道做完的產出，要轉給下一道接著做——誰的貨、從哪到哪、送了多少、到了沒。它把過去靠紙本工單跟著貨走的流轉，變成系統裡可追蹤、可作為下游到料放行的紀錄。**單據由系統於[[廠務]]確認搬運時自動生成**（轉交是常態且滾動，設計核心是「系統告訴下一步」、不是人建表單）——師傅報工累積可轉交量、廠務的待搬清單滾動顯示可送的貨，廠務挑貨搬運、確認送達（附簽收照）即成單；[[印務]]只處理例外（作廢、改路徑）。

轉交涵蓋場內站間移動，**暫存區是合法的來源與目的地站點**——工廠的暫存區同時放外發回貨、待品檢、品檢完待裝箱、裝箱完待出貨的貨，貨進出暫存區都以轉交留痕，系統才答得出「這批貨在哪」。三類常態轉交：產線 → 產線（或品檢區）、**暫存區 → 產線**（外發回貨點收完成後，下游到料放行觸發待搬清單）、**品檢區 → 暫存區**（品檢通過成品入暫存區，見 [[PT-011-成品移轉揀貨暫存區的搬運留痕]] 決議）。場外回場內的物流本身走 [[貨運單]]（中國線）與 [[生產任務狀態]] 在途狀態，非轉交單範圍；台灣外包回場銜接由 [[揀貨人員]] 直接對生產任務點收、確認即自動完成（[[PT-008-外發回廠流轉的系統設計範圍]] 決議，已封存），見 [[印件生產流程]] § 外發回場銜接。

轉交單是 [[工序相依性規則]] 中「需轉交才可製作」的載體——下一道工序的到料量看「轉交單已送達的數量」，到料量大於 0 即可開工、滾動累積（數量級放行，正本見 [[工序相依性規則]]）。生產任務**預設需轉交**，印務在製程規劃時只標例外「不需轉交」。

## 欄位（業務可見）

> 標注「建立時設定」的欄位由系統於生成時自動帶入（目的地從下一道任務的產線帶出、明細預設帶可轉交全量），廠務確認搬運時可調實搬數量；操作介面與待搬清單的呈現屬後續系統設計。

| 欄位 | 說明 | 編輯 |
|------|------|------|
| 轉交單編號 | 格式 TT-YYYYMMDD-NNN | 系統產生 |
| 印件 | 這趟運送屬於哪張印件（單一、不跨印件） | 建立時設定、唯讀 |
| 狀態 | 運送中／已送達／已作廢（見 [[轉交單狀態]]） | 系統依操作推進 |
| 對象類型 | 內部產線／外部廠商 | 建立時設定 |
| 目的產線 | 對象＝內部產線時必填（送到哪條產線） | 建立時設定 |
| 目的廠商 | 對象＝外部廠商時必填（送到哪家外包廠） | 建立時設定 |
| 運送方式 | 廠內自送／貨運行／供應商自取／其他 | 建立時設定 |
| 貨運行名稱 | 運送方式＝貨運行時必填 | 建立時設定 |
| 廠內執行者 | 實際搬運的廠務姓名 | 可填 |
| 明細 | 至少一條轉交明細（生產任務×數量，見下） | 建立時設定 |
| 預計轉交日 | 預計哪天送 | 可填 |
| 實際轉交日 | 確認送達時系統寫入當日 | 系統自動、唯讀 |
| 確認操作人 | 確認送達的廠務 | 系統自動、唯讀 |
| 簽收照片 | 送達憑證 | 可附 |
| 作廢時間／操作人／原因 | 作廢相關 | 作廢時填 |
| 備註 | | 可填 |

### 轉交明細（每條＝從一個生產任務抽取的部分數量）

| 欄位 | 說明 |
|------|------|
| 生產任務 | 這條明細抽哪個生產任務的量（必須屬於本轉交單的印件） |
| 數量 | 大於 0，不超過該生產任務的可申請上限（見下） |

## 關鍵關聯

- 屬於一張 [[印件]]（單一、不跨印件）
- 明細指向多筆 [[生產任務]]（同印件、可跨工單）
- 作為 [[工序相依性規則]] 中下游任務的到料依據（已送達數量計入下游到料量、滾動放行）

資料約束（本卡自身的完整性條件，數量上限公式正本在 [[齊套邏輯]]、放行規則正本在 [[工序相依性規則]]）：

- 一張轉交單的所有明細必須同屬一張印件
- 同一筆生產任務不可在一張轉交單的明細出現兩次
- 建立前置：貨要先存在才有得搬——產線間轉交以來源生產任務已有報工量為前提、暫存區至產線以該批貨已完成點收登記為前提、品檢區至暫存區以品檢通過量為前提
