# 出貨單（ShipmentRecord）

讀完這張卡，你會知道：

- 說出出貨單在訂單交付裡扮演什麼角色、為什麼每一次出貨都要獨立成一張單
- 說出一次出貨的範圍怎麼定——同一張訂單的多種印件可以合箱、不可跨訂單，每種各出多少記在哪裡
- 找到業務、揀貨人員與出貨人員在一張出貨單上看得到的每個欄位，說出它從哪來、誰填、什麼時候填
- 判斷一次最多能出多少（上限是品檢通過累計出來的完工良品數），以及作廢或異常後各印件的額度怎麼回補
- 分辨自取、專車配送與第三方物流三種出貨方式走的路差在哪，說出出貨與送達各憑什麼認定，以及狀態名在哪張卡

## 營運背景

訂單做完不等於交完——同一張訂單的東西可能分批出、多種印件合在一起出、用不同方式出（宅配、超商、司機配送或客戶自取），每批要能追蹤到了沒。[[業務]]填出貨單決定這一次怎麼出：要合／不合、每種出多少、送到哪，以此告訴揀貨與出貨人員。把每次出貨獨立成一張出貨單，是因為出貨額度要對著完工良品數管控（品檢通過才計入、出貨不能超過額度），分批與作廢都要能逐印件回算額度，沒有獨立單據這筆帳算不清。

## 欄位（業務可見）

> 本段是該實體的欄位正本。欄位的新增與修改是商業決策，直接在本卡維護。欄位依雛形系統既有介面整理。

| 介面欄位 | 說明 | 欄位形態 | 來源 | 可否修改 |
|---------|------|---------|------|---------|
| 所屬訂單 | 這張出貨單屬於哪張訂單 | 連結（指向 [[訂單]]）| 建單時帶入 | 不可 |
| 出貨明細 | 這次出哪些印件、各多少（見下方明細子表；可含同訂單多種印件、不可跨訂單）| 明細（多筆）| 業務建單時選擇 | 建單時設定 |
| 收件資訊 | 送到哪、給誰收（收件人／地址／電話）| 文字 | 業務建單時填寫 | 建單時填寫 |
| 裝箱指示 | 業務對裝箱方式的指定（如「200 個一箱」）；未填時揀貨人員自行依公版箱規判斷 | 文字 | 業務建單時填寫（選填）| 建單時填寫 |
| 出貨方式 | 自取／專車配送（公司自行配送）／第三方物流；自取不經運送中（規則正本見 [[出貨單狀態]]）。建單時自 [[印件]] 的出貨方式（客戶下單時的預設偏好）帶入、可改，實際出貨以本欄為準（分批可各批不同方式）| 單選 | 業務建單時選擇（自印件帶入預設）| 建單時選擇 |
| 物流商 | 出貨方式＝第三方物流時必填（順豐／新竹物流／超商／其他，選項可增不改流程）| 單選 | 業務建單時選擇 | 建單時選擇 |
| 狀態 | 目前的出貨進度 | 單選（依 [[出貨單狀態]] 定義）| 揀貨段揀貨人員推進、物流段出貨人員推進 | 依狀態機規則 |
| 實際裝箱數量 | 揀貨清點後實際裝箱的總個數；與出貨明細要求不符時照實填寫，於系統外通知業務處理（系統不設異常回報功能，規則見 [[出貨單狀態]]）| 數字 | 揀貨人員裝箱回報時填 | 回報時填寫 |
| 箱數 | 裝成幾箱 | 數字 | 揀貨人員裝箱回報時填 | 回報時填寫 |
| 每箱幾個 | 一箱裝幾個（業務有填裝箱指示就照指示裝、沒填則依公版箱規判斷後照實填）；同一張出貨單多種印件合箱時，本欄填**主品項**的每箱數，混裝的細節寫在裝箱指示或備註——這個數是給對帳與交接看的概數，不必為了混裝把一個欄位拆成一張表 | 數字 | 揀貨人員裝箱回報時填 | 回報時填寫 |
| 箱規 | 用哪種公版箱體（對應第三方物流箱數計價；留存供每月對帳比對）| 單選（公版箱體）| 揀貨人員裝箱回報時選 | 回報時選擇 |
| 裝箱照片 | 裝箱照、秤重照 | 檔案上傳（多檔）| 揀貨人員裝箱回報時附 | 回報時上傳 |
| 出貨確認 | 貨離廠的確認：時間＋操作人；第三方物流另填托運單號（追蹤碼）| 日期時間＋人員（唯讀）＋文字 | 出貨人員確認時系統寫入、托運單號手填 | 托運單號可補填 |
| 送達確認 | 貨到客戶手上的確認：時間＋操作人＋**送達憑證**（專車＝司機交付照、自取＝現場點交照、第三方＝回填物流商配達時間）| 日期時間＋人員（唯讀）＋檔案或文字 | 出貨人員確認時寫入 | 憑證可補附 |
| 作廢／異常理由與時間 | 收於「已作廢」或「異常」兩個終態時皆必填理由，系統一併記下轉入該終態的時間。為什麼要存：這兩個終態都會逐印件回補可出貨額度，事後追「這批貨為什麼沒送成、額度何時回來的」只剩這一筆記錄；異常不細分原因分類，理由以自由文字承接 | 文字＋日期時間（唯讀）| 轉入終態時寫入 | 不可 |

### 出貨明細（每條＝一種印件出多少）

| 欄位 | 說明 |
|------|------|
| 印件 | 出的是哪件印刷品（必須屬於本出貨單的訂單） |
| 數量 | 大於 0，不超過該印件的可出貨額度（算式正本見 [[印件]] 可出貨額度欄；作廢與異常皆自動回補） |

> 範圍外點名：內部主鍵、訂單與印件關聯鍵，存在但屬實作規格。分批出貨已拍板（2026-07-21，[[SHP-005-分批出貨觸發節點]] 決議）：業務於訂單詳情印件列看「可出貨數／已出貨／總量」、建單時逐明細即時檢核，不設特例機制與建議提示。運費的帳不做——箱數／箱規留存供每月與第三方物流對帳比對（對帳機制屬後續設計）。

## 關鍵關聯

- 屬於 [[訂單]]（N:1）：一張訂單可分批出貨、有多張出貨單
- 出貨明細指向多筆 [[印件]]（同訂單、可多種印件合箱；2026-07-20 拍板）：額度檢查、作廢回補、送達累計逐明細行對印件計算（額度與送達累計的欄位見 [[印件]]，回補規則見 [[齊套邏輯]]）；狀態掛單頭，一箱貨一起送達、一起異常
- 上游依賴 [[品檢紀錄]]（印件層，[[QC]] 已退役）：品檢通過累計＝完工良品數，完工良品數決定可出貨額度
