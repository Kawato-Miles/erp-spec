# 訂單異動（OrderAdjustment）

讀完這張卡，你會知道：

- 認出一張訂單異動上看得到哪些資料，以及各欄由哪個操作填、什麼時候填
- 分辨哪些欄位能改、改的時機到哪裡為止、哪些是系統寫入後唯讀
- 看懂核可金額與異動金額並列在一起是要對照什麼
- 說出訂單異動上能做哪些操作、各屬哪個動作類型
- 找到這張單與訂單、售後服務單之間怎麼掛

## 營運背景

訂單異動是訂單成立後一筆金額增減的單據：多收客戶錢（補收）或退錢給客戶（退款）都記在這裡。

- 為什麼獨立存在：印刷廠接單後金額常臨時變動（追加印量、改急件、補運費，或品質規格不符要退費），金額增減要有完整的審核與認列軌跡，不能靜默改掉訂單總價。
- 為什麼獨立於主訂單狀態：訂單異動在等核可時，主訂單的生產與出貨照常往前走（見 [[訂單異動狀態]]）。
- 補收與退款的把關強度不同：錢退出去出錯難追回，客戶加單是送上門的生意，分權正本見 [[現金流出把關]] 與 [[訂單異動規則]]。

## 異動類型與金額方向

各類型能填的金額方向固定，填反了系統擋下。這是為了讓應收總額的加減與異動類型對得起來——加印卻記成負數，事後看帳會以為退了錢。

| 異動類型 | 金額方向 |
|---|---|
| 加印追加、加運費、急件費 | 只能是正數（補收） |
| 退印、折扣 | 只能是負數（退款） |
| 規格變更、補退、其他 | 正負皆可 |
| 諮詢取消退費（系統內生） | 只能是負數 |

## 操作

| 操作編號 | 操作 | 動作類型 |
|---------|------|---------|
| OP-ADJ-001 | 編輯訂單異動 | 編輯 |
| OP-ADJ-002 | 提交審核 | 狀態推進 |
| OP-ADJ-003 | 核可訂單異動 | 審核 |
| OP-ADJ-004 | 退回訂單異動 | 審核 |
| OP-ADJ-005 | 確認生效 | 狀態推進 |
| OP-ADJ-006 | 取消訂單異動 | 刪除或作廢 |
| OP-ADJ-007 | 取消已認列的訂單異動 | 刪除或作廢 |

無操作的動作類型：建立（在訂單上建立，登記在 [[訂單]] OP-ORD-006 建立訂單異動；在售後服務單上建立，登記在 [[售後服務]] OP-AFT-005 建立訂單異動；諮詢取消退費由系統建立）、指派或改派（訂單異動沒有負責人欄位，跟著所屬訂單）、分享管理（訂單異動沒有分享成員，分享沿用所屬訂單）、檢視（隨所屬訂單檢視，見 [[訂單]] OP-ORD-020 檢視訂單）、輸出

- OP-ADJ-001 編輯訂單異動涵蓋異動類型、異動金額、異動原因的修改；各欄可改到什麼時候見上方可否修改欄。
- OP-ADJ-002 提交審核涵蓋草稿第一次送審與已退回後重新送審。
- OP-ADJ-003 核可訂單異動與 OP-ADJ-004 退回訂單異動是同一關的兩種結果，業務動作不同而分立。
- OP-ADJ-006 取消訂單異動與 OP-ADJ-007 取消已認列的訂單異動分立，是因為能執行的人不同：金額已認列後的取消另有把關（規則見 [[訂單異動規則#什麼時候可以取消]]）。
