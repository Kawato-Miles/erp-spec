# 工序主檔（Process Master）

讀完這張卡，你會知道：

- 說出工序主檔登錄什麼：製版、印刷、上光、裁切、裝訂前加工、手工、外包等每一道加工動作怎麼計價、由誰承作
- 找到一道工序與一個工序群組各記哪些欄位，以及群組與工序之間的主從關係
- 列出工序可選的八種計價方法各用什麼維度計價、適合哪一類加工
- 分辨印刷的計價與後加工的計價各掛在哪一層，以及為什麼分兩邊記
- 說出一道工序實際由哪台設備執行是在什麼時候決定的

## 營運背景

工序主檔是什麼見 [[ERP 詞彙表#工序主檔]]。

報價與規格階段就要算「這道加工動作要多少錢」。公司把每一道可重用的加工動作獨立成主檔：上層先用工序群組（如表面處理、燙金燙銀、模切、壓線、打孔）分類，群組下掛各道工序，每道工序指定一種計價方法、一個承作廠商。工序是 [[部件配方]] 工序段引用的對象，配方逐段選一道工序、決定這個部件怎麼做、多少錢。工序主檔與 [[裝訂主檔]] 的合稱見 [[ERP 詞彙表#製程類主檔]]。

印刷在現況成本模型裡的計價掛在設備、而非工序：印刷計價（開機費、令數／千車階梯、色數與特殊色倍率、放損率）掛在設備，見 [[設備]]；本卡工序主檔承載的是後加工工序（覆膜、燙金、壓線等）的計價，八種計價方法擇一；印刷工序在本卡另配自己的牌價（上機的工資與版材）；工序型生產任務的任務小計算式正本見 [[成本計算規則]] § 計價引擎計算框架。誰新增與維護工序主檔見 [[品項與製程主檔維護活動清單]]。承作廠商（工序廠商）記在工序上，記這道工序由哪一家承作；整段生產走場內（自有工廠、加工廠）或外包（台灣外包、中國外包），由工序、裝訂主檔的承作廠商決定、展開時帶出 [[生產任務]] 的「廠商類別」欄位；材料型生產任務的廠商類別來源見 [[PT-071-材料型生產任務的廠商類別來源]]。

## 欄位（業務可見）

> 本段是該實體的欄位正本。欄位的新增與修改是商業決策，直接在本卡維護。工序計價方法是本卡承載的核心，計算公式不在此複寫、見 [[成本計算規則#工序費]]。

#### 計價方法列舉（共八種）

> 計價方法決定這道工序用什麼維度查價、乘什麼用量。每種方法對應的計價設定（區間矩陣或級距表）與計算公式正本見 [[成本計算規則#工序費]]，本卡只列舉方法名稱與適用場景。

| 計價方法 | 用什麼維度計價 | 典型適用 |
|---------|--------------|---------|
| 成品計價 | 成品面積（平方公分或平方公尺）與數量兩軸查價 | 滿版處理工藝，如覆膜、過油 |
| 工序面積 | 工序處理面積（平方公分或平方公尺）與數量兩軸查價 | 非滿版工藝，如燙金、局部上光、打凸 |
| 時間計價 | 每件加工時間（秒、分鐘或小時，依該工序價格表設定）與數量兩軸查價 | 依設備加工時間計費的工序 |
| 成品數量 | 成品件數的級距 | 按件計費的工序 |
| 原紙張數 | 原紙張數的級距 | 獨立版覆膜、上光等，僅限獨立版 |
| 原紙令數 | 原紙令數的級距（一令為五百張全開紙）| 按令計費的工序 |
| 上機印數 | 上機次數的級距 | 按上機次數計費的工序 |
| 工序總價 | 直接給整批總價、不乘數量 | 車縫邊等整批一口價的工序 |

> 範圍外點名：各計價設定的區間／級距明細列、版本流水序號，存在但屬實作規格，不列入欄位表。

## 相關狀態機

本實體無獨立業務狀態機。工序與工序群組的生命週期以各自「啟用狀態」欄位（啟用／停用）表達，由維護者直接切換，不另立狀態機卡。
