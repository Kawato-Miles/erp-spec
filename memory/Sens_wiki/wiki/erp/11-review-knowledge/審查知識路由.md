# 審查知識路由

> 此目錄為 ERP 規劃品質稽核的方法論層，與 01-10 業務層並列。
> **2026-08-05 切換**：舊三 agent 序列協作模式除役（協議卡與 agent 檔已刪，決策脈絡見 wiki/log.md 2026-08-04／2026-08-05 條目），現行為「主對話設計＋rubric 稽核」——設計照 `plan-design` skill、稽核照 `plan-audit` skill，量尺正本 [[規劃品質評分準則]]。

## 一、定位

- **承載內容**：規劃品質量尺（rubric）、稽核誤判案例、稽核方法論素材
- **不承載內容**：業務邏輯／實體／狀態機／角色（在 02-07）；skill 的觸發設定與流程（在 `.claude/skills/`）；領域專屬檢核素材（在各領域正本卡，依 [[規劃品質評分準則]] § 六規則分層）

## 二、目錄結構

```
11-review-knowledge/
├── 審查知識路由.md            入口（本檔）
├── 規劃品質評分準則.md         量尺唯一正本（plan-design 照它寫、plan-audit 照它驗）
├── 稽核誤判記錄.md             稽核者誤判案例庫（misjudgement-record skill 追加）
└── _shared/                    跨用途稽核素材
    ├── audit-failure-patterns.md            稽核失效模式（erp-planning-pre-check 引用）
    ├── archive-completeness-misjudgement.md  archive 完整性誤判案例
    └── e2e-planning-checklist.md            端對端測試規劃檢核
```

## 三、流程對照

| 階段 | 依據 |
|------|------|
| 需求對齊 | `grilling` skill（Miles 於提需求時下達）＋ `erp-planning-pre-check` 盤點 |
| 設計 | `plan-design` skill（五必含段收件模板）|
| 稽核 | `plan-audit` skill（三值判定＋證據；結構性變更加雙盲對抗推演）|
| 誤判回饋 | `misjudgement-record` skill → [[稽核誤判記錄]] |
