# PT-063 外發回台的貨送場內後段產線時，走不走轉交單

## 問題描述

外發工序做完、貨回台點收後，要送場內下一道工序時，正本寫法互相矛盾。矛盾來自既有正本。

| 來源 | 寫法 |
|---|---|
| [[轉交單]] 營運背景 | 只寫一條路：生管建目的地為品檢站的轉交單 |
| [[外發委外與回廠點收]] 主流程與相關段 | 下一站依 [[工序相依性規則]] 兩軌放行，需轉交的看轉交單已點收量，可送後段產線 |
| production-execution spec 場內轉交適用路徑 | 可送後段所在產線 |
| [[場內轉交與更正]] 範圍外 | 外發回廠不走轉交單（指海外回台物流段） |

Miles 2026-09-24 指定：外發回台後的轉交細節本次不處理；原則是外發在工單上也是生產任務，報工與轉交同一套規則。

## 待解答

- [ ] 外發回台後送場內後段產線，是否走轉交單（目的地取外發任務的目的站點）？

裁決後要同步的位置：[[轉交單]]、[[場內轉交與更正]]、[[外發委外與回廠點收]]。
