# BI-005 對帳匯出檔十四欄是否符合會計月結實務

## 問題描述

對帳匯出檔（CSV）的十四欄由 Miles 定稿，欄序為帳務公司、發票號碼、訂單編號、案名、開立日期、應收日期、客戶名稱、總金額（含稅）、備註、收款日期、收款狀態、業務名稱、開立日期月底、天數（應收日減開立日）。這份欄位表沒有經過會計本人確認，只是設計者對月結對帳流程的推想。會計拿到檔案後若還得再開試算表拼湊，這個功能的效益就不成立。

範圍宣告：本卡只管十四欄對會計月結實務的適用性，涉及 [[會計]] 的實際對帳動作。欄位本身的計算口徑與金額規則不在本卡範圍。

確認方式已定，不獨立約訪談：併入應收帳款報表後端實作的驗收場，與會計一次過完下列各項；驗收時點由 Miles 排。

## 待解答

- [ ] 十四欄的現行欄序，會計拿到後能不能直接用、不必再調欄？
- [ ] 十四欄之外，會計還需要哪些欄（折讓金額、折讓後淨額、帳齡、款項方式、退款明細）？
- [ ] 「開立日期月底」這一欄，會計實際拿它當帳齡起算基準嗎？
- [ ] 「天數」這一欄（應收日減開立日），會計實際拿來做什麼分析？
- [ ] 一張發票經多次部分收款時，「收款日期」該取最近一次收款日還是結清日？
- [ ] 作廢發票要不要提供列入匯出檔的選項？

## 部分拍板

- 確認方式已定（2026-08-04，Miles）：不獨立約訪談，併入應收帳款報表後端實作的驗收場，屆時與會計一次過完上列各項；本卡維持 open 至該場確認完成。
