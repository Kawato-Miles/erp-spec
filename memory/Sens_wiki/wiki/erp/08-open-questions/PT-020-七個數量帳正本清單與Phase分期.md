# PT-020 七個數量帳正本清單與 Phase 分期

## 問題描述

生產階段的數量帳三處說法不一致，且壞掉那側的帳沒有落點：

1. **清單不一**：架構卡列七個數量（目標／生產／良品不良品／不良品處置／完工良品／入庫／出貨），[[齊套邏輯]] 正文寫「貫穿六個數量」、守恆鏈只列四項（報工完成數 ≥ 品檢通過累計 ≥ 已出貨數 ≥ 累計送達數）。
2. **報廢數無落點**：全卡未出現報廢數，但 [[生產績效指標]] 折損率的分子取的正是報廢數；報工不良品數、品檢不通過數、報廢數三者的關係與去重口徑歸 [[QC-004-報工不良與品檢缺口取數口徑|QC-004]]，本卡銜接其結論。
3. **Phase 分期未標**：Phase 1 入庫數＝完工良品數（同一個數），[[成品庫存]] 啟用後（Phase 2/3）才分離為兩個數；數量帳定義若不標分期，Phase 1 會出現一個無實體承載的入庫數。
4. **工單層完工良品數欄位去留**：品檢移印件層（2026-07-21 拍板）後，[[工單]] 欄位表的「完工良品數」層級歸屬待定（工單卡已標註引用本卡）。

## 待解答

- [ ] 七個數量帳的正本清單與各自定義（含報廢數落點），正本落 [[齊套邏輯]]
- [ ] 守恆鏈是否擴充（不良／缺口側入帳，依 QC-004 結論）
- [ ] Phase 1 與 Phase 2/3 的分期標註方式
- [ ] 工單層完工良品數欄位的去留與印件層帳的對應
