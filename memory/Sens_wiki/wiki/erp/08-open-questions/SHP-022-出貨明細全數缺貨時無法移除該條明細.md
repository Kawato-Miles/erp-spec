# SHP-022 出貨明細某一條全數缺貨時，只能作廢整張出貨單重建

## 問題描述

現況出貨明細數量必須大於 0，建立後業務只能改數量、不能移除明細（[[出貨單]]）。一張單合出多件印件時，若其中一件在揀貨時完全找不到：

| 步驟 | 結果 |
|------|------|
| 揀貨人員填該條揀貨數量 0 | 不符，2026-10-12 起擋下出貨 |
| 業務想把該條改成 0 | 數量須大於 0，改不了 |
| 業務想移除該條 | 沒有移除路徑 |
| 只剩作廢整張單 | 其他已裝好的印件要拆箱歸位，再建新單重揀 |

另外，揀貨數量能不能填 0 也沒寫。

矛盾來自既有正本（明細數量大於 0、不能移除）與本次討論新增的不符擋下規則疊加。

## 待解答

- [ ] 未離廠的出貨單，業務能不能移除某一條明細？
- [ ] 揀貨數量能不能填 0？

## 候選方案

- **A（未離廠可移除明細）**：打包中、待出貨可移除明細，至少留一條；移除即回補該條額度。代價：裝箱回報要跟著重看。
- **B（維持作廢重建）**：不開移除。代價：現場重做整單。

不受影響項：已離廠的出貨單、額度算式。

裁決後要同步的位置：[[出貨單]]、[[出貨單狀態]]、[[出貨與送達]]。
