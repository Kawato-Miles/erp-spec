# ORD-061 線上單整單製作天數與兩個預計出貨日的推算輸入與規則

## 問題描述

急件新定義已拍板線上單的原則：整單製作天數＝max（各印件製作天數 − 凍結天數）；審稿前預計出貨日＝下單（付款）日加整單製作天數；審稿後預計出貨日＝最後一件印件首次進入「已確認可製作」那天加整單製作天數（欄位正本見 [[訂單]]，凍結天數見 [[急件主檔]] 與 [[印件]]）。

原則已定，但算式的輸入與細節在正本中查不到：

- 各印件的製作天數：正本沒有來源欄。
- 下單（付款）日：[[訂單]] 沒有對應欄。
- 印件首次進入已確認可製作的時點：正本沒有時間點欄。
- 製作天數的單位（工作天或日曆天）、整單製作天數有無下限（單印件製作天數 2、急件 3 時得 −1）、付款日落在非工作天時從哪天起算，都沒有定義。[[工作天規則]] 範圍外宣告「起算日與商品工作天屬線上商城整合另案」。
- 「最後一件印件」是否排除已棄用印件、是否計入打樣 NG 複製的新印件；審稿後預計出貨日是一次寫入還是即時重算。
- 線上單改急件選項時，兩個預計出貨日是否重算（線下單拍板為不重算、不同步）。

本卡範圍：線上單這兩個預計出貨日與整單製作天數的推算輸入與規則。不含印件層日期（見 [[ORD-062-線上單印件層沒有日期時排程與指標的基準]]）、不含 EC 前台帶入欄位的介面。屬本次討論產生，不是既有正本矛盾。

## 待解答

- [ ] 各印件製作天數、下單（付款）日、首次進入已確認可製作的時點，各從哪個來源取？
- [ ] 製作天數用工作天或日曆天？整單製作天數有無下限？付款日落在非工作天時從哪天起算？
- [ ] 「最後一件印件」的範圍（已棄用、打樣 NG 新印件）與審稿後預計出貨日的寫入時點？
- [ ] 線上單改急件選項時，兩個預計出貨日是否重算？

## 裁決後要同步的位置

[[訂單]] 兩個預計出貨日欄的算式與來源；[[工作天規則]] 的範圍外宣告；[[印件]] 與 [[急件主檔]] 的線上單用途說明；change rush-order-definition 的 specs（本卡拍板前，線上單推算行為不寫入 specs）。
