# PI-003：印件轉「已棄用」時工單的連動行為

## 問題描述

Miles 已拍板（2026-06-11）：「已棄用」是印件印製維度的終態，用於訂單取消、單一印件取消製作等情境，且要連動到生產任務的報廢，以利計算當前已報工的成本。生產任務那一層的連動已明確——已報工的轉「報廢」（結算成本）、未開工的轉「已作廢」（無成本）。

中間缺的是工單這一層：

- **訂單取消時**：工單有現成的「訂單取消連鎖 → 已取消」路徑（[[工單狀態]]），但由下而上收斂的條件是旗下生產任務全部作廢；一旦出現「部分報廢、部分作廢」的混合，條件不成立，工單會停在原狀態下不來。
- **單一印件取消製作時**：訂單還在，沒有訂單取消連鎖可走，工單轉「已取消」的觸發是什麼沒有定義，或者工單需要另一條「印件棄用連鎖」。

範圍限工單層的連動狀態與觸發語意。印件層終態與生產任務層的報廢／作廢分流已拍板，不在本卡待解範圍。

## 待解答

- [ ] 單一印件取消製作時，該印件下的工單轉什麼狀態、觸發語意怎麼描述？
- [ ] 旗下生產任務出現「報廢＋作廢混合」時，工單由下而上收斂的條件怎麼寫？

## 涉及範圍

- [[工單狀態]] 轉換表「已取消」的觸發事件欄（目前只寫訂單取消連鎖）
- [[工單狀態]] 由下而上收斂的條件（2026-07-28 任務實體移除後，原任務層「所有生產任務皆作廢」的彙整規則改由工單層承接，現行寫法未涵蓋報廢混合）
- [[印件狀態]] 關係段（目前標注本卡）
