# CR-008 諮詢表單自動建單失敗時的補救分工與對客時限

## 問題描述

金流平台已向客戶扣款成功，系統卻沒能自動建立諮詢單（必填欄位缺漏、表單內容異動被系統拒收、或系統當下無法處理）。此時客戶的錢已經收了，系統裡卻沒有對應的諮詢單與付款紀錄可供諮詢人員認領與服務，形成收了錢卻無人接住的缺口。補救由誰做、多久內要做到，目前沒有定義。

範圍宣告：本卡只管自動建單失敗後的補救分工、對客時限與補建方式，涉及 [[諮詢表單自動建單串接約束]]。

## 待解答

- [ ] 建單失敗時由誰負責補救，值班業務、工程值班，還是兩者分工？
- [ ] 對客戶承諾多久內完成手動建單或主動聯繫？
- [ ] 補建方式採人工補入系統，還是請客戶重填表單？
