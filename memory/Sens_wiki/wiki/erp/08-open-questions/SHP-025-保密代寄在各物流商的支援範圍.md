# SHP-025 保密代寄在各物流商的支援範圍

## 問題描述

Miles 2026-10-20 拍板（G30）：業務可勾「保密代寄」，改用自訂寄件人名義寄出，不用感官、理想的名義。

sensation-api 現況與這個拍板不一致：

| 物流商 | 現況 |
|---|---|
| 順豐、新竹物流 | 支援保密代寄（is_delivery_private），自訂寄件人要分開填郵遞區號、縣市、區，電話與市話擇一必填 |
| 全家 | 寄件人固定取設定檔，不讀自訂寄件人 |
| 7-11 交貨便（payuni） | 拋單不傳寄件人 |
| 順豐、新竹物流（非保密代寄時） | 一律用設定檔的單一預設寄件人，不依帳務公司（感官或理想） |

結果：保密代寄搭配全家或 7-11 交貨便時，ERP 顯示的寄件人與實際包裹上的不同，G30 的目的沒有達成。非保密代寄時，帳務公司是理想印制的單，實際寄件人仍是預設值。矛盾來自本次拍板與後端現況。

範圍宣告：本卡只管保密代寄與帳務公司寄件人在各物流商拋單時能否生效。保密代寄的欄位與可改時點已拍板，不在本卡。

## 待解答

- [ ] 保密代寄在全家、7-11 交貨便不生效時怎麼處理？
- [ ] 非保密代寄時，拋單寄件人要不要改為依帳務公司？

## 候選方案

- **A（限定出貨方式）**：保密代寄只開放順豐、新竹物流、自取、專車、其他；超商不開放勾選。代價：超商出貨無法代寄。
- **B（後端擴充）**：請後端確認全家、7-11 交貨便能否帶自訂寄件人並擴充。代價：依賴物流商介面與後端排程。
- **C（接受不一致）**：畫面照存，實際寄件人以物流商為準，業務自行注意。代價：顯示與實際不符。

不受影響項：保密代寄的欄位、預設值與可改時點。
裁決後要同步的位置：[[出貨單]] 寄件資訊欄與保密代寄欄；[[出貨與送達]] 情境；Prototype 保密代寄勾選框的開放條件。
