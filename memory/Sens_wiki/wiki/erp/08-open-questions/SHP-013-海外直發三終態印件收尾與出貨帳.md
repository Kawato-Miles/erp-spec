# SHP-013 海外直發三終態的印件收尾與出貨帳

## 問題描述

[[派單狀態]] 有三個海外直發終態（分批／全出／送大陸客戶），貨不回台、不經場內最終品檢、不走台灣 [[出貨單]]；但 [[印件生產流程]] 的三條印件完成路徑（完全廠內／廠內＋外發／完全外發）終點都是回台品檢入庫再出貨，海外直發是缺席的第四條路徑：

1. 印件的入庫數（＝品檢通過累計）與可出貨額度在貨不回台時如何成立。
2. 印件「已送達」收尾與訂單完成怎麼觸發（無台灣出貨單可依）。
3. 品質責任與驗收憑證由誰承載（大陸客戶簽收？中國廠自檢？）。

## 待解答

- [ ] 海外直發路徑的數量帳成立方式（是否以派單終態代品檢入庫）
- [ ] 印件與訂單收尾的觸發來源
- [ ] [[印件生產流程]] 補第四條完成路徑
