# PT-065 已完成的生產任務再報工時，是否受所屬工單已完成或印件印製維度已到終態的限制

## 問題描述

2026-10-04 拍板只定任務層：生產任務已完成後仍可再報工，任務維持已完成（[[生產任務狀態]]、[[報工紀錄]]）。拍板沒有說工單或印件到終態時是否還能再報工。

既有正本另有一條補做邊界：工單「已完成 → 異動」的一般補做，在所屬印件印製維度已到終態時擋下（[[工單狀態]]，依據 [[PT-034-工單補做重開守衛邊界]]）。這條邊界保護的是已鎖定的出貨帳不被回頭翻動。

直接對已完成的任務再報工，不經工單異動這一關。兩條規則並存時的結果如下。

| 情形 | 結果 |
|------|------|
| 訂單已完成，師傅誤對已完成的裁切任務報工 50 | 所屬 [[印件]] 的待驗量從 0 變 50 |
| 同上 | 實際成本在訂單完成後上升 |
| 印件印製維度已到「已送達」 | 補做走工單異動會被擋下，直接再報工卻不會 |

矛盾性質：本次討論產生。一方是 2026-10-04 拍板的任務層再報工；另一方是 PT-034 封存決議保護的出貨帳邊界。

為什麼拍板原則回答不了：「不加新把關」指向不限制；「沿用既有機制」指向套用 PT-034 既有邊界。兩條原則在這裡給出相反答案，要 Miles 選邊。

本卡只管再報工的範圍邊界。搬運短少的補做流程見 [[場內轉交與更正]]，不在本卡。

## 待解答

- [ ] 生產任務已完成後再報工，在所屬工單已完成、印件印製維度已到終態、或訂單已到終態時，是否擋下？

## 候選方案

- **A（不限制）**：照拍板任務層字面；誤報以報工修改改回。代價：印件已送達後待驗量與實際成本仍會被改動，PT-034 保護的出貨帳可能被翻動。
- **B（沿用 PT-034 邊界）**：所屬工單已完成、或印件印製維度已到終態時擋下再報工；此時補做改走工單異動加開。代價：多一道擋下；搬運短少的補做多發生在工單未完成期間，不受影響。
- **C（只看訂單終態）**：只在訂單已到終態時擋下。代價：新增一條既有正本沒有的判準。

不受影響項：任務層「已完成後再報工、任務維持已完成」本身；報工修改與作廢的擋下條件。

裁決後要同步的位置：[[生產任務狀態]]（已完成 → 已完成維持那一列）、[[報工紀錄]] § 相關狀態機、[[場內轉交與更正]]（報工擋下條件正本）。
