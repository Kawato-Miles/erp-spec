# PT-026 外部廠商協作門戶的身分與可視邊界

## 問題描述

派單已裁決為「外部廠商協作門戶」（2026-07-22），廠商在派單上回寫報價、製作狀況、填運單，但門戶的身分與邊界無任何卡定義：

1. 廠商帳號如何建立與停用（身分模型）。
2. 可視範圍：只能看被派給自己的派單與工單指示、不得看到其他廠商報價與客戶資訊；客戶稿件外流的營業秘密邊界。
3. 報價回寫的權限與時效。
4. [[外包廠商]] 卡「預期阻力」仍寫「系統尚未支援時以紙本傳真作為過渡」，與門戶化方向未對齊（門戶推行時的過渡策略）。

## 待解答

- [ ] 廠商身分模型與帳號生命週期
- [ ] 門戶可視範圍與稿件保密邊界
- [ ] 報價回寫權限與時效
- [ ] 紙本過渡與門戶推行的並存策略
