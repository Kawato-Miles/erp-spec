# QC-005 不符合報告單的實體歸屬與欄位正本

## 問題描述

「不符合報告單」被印件狀態、生產任務狀態、品檢人員、生產績效指標、齊套邏輯、打樣流程六張卡當成既有載體引用（打樣 NG-製程問題明定「系統自動開一張全欄位預填、即開即結的不符合報告單」作結構化留底），但 `05-entities/` 無此實體卡：

1. 欄位無正本：原因分類、處置分流、數量、關聯印件或工單、即開即結語意皆無定義。
2. 與 [[品檢紀錄]] 的基數未定（一筆品檢紀錄對一張報告單？印件層彙總？），品檢正本卡全文未提及它。
3. QC 不通過的補做／客戶照收／報廢三分流是否共用同一單據未定。

## 待解答

- [ ] 是否開獨立實體卡（或併入品檢紀錄為子紀錄）
- [ ] 欄位正本與即開即結語意
- [ ] 與品檢紀錄的基數
- [ ] 打樣 NG 與 QC 不通過是否共用同一單據
