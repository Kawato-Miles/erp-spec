# ORD-053 訂單完成後可否編輯四張情境卡說法不一

## 問題描述

四張訂單領域的情境卡，對「訂單進入『訂單完成』之後還能不能編輯」給出兩種相反的答案。

| 卡 | 說法 |
|---|---|
| [[訂單印件規格維護]] | 訂單進入「訂單完成」或「已取消」任一終態後，所有印件欄位含金額一律唯讀 |
| [[訂單客戶與聯絡資料維護]] | 訂單進到「訂單完成」或「已取消」後，客戶與窗口聯絡人一律停用編輯、僅唯讀顯示 |
| [[訂單資訊分區編輯]] | 訂單為「訂單完成」後四個區塊仍可繼續編輯，直到被取消為止 |
| [[訂單三類備註維護]] | 只要該訂單尚未取消即可編輯，含訂單已是「訂單完成」終態後仍可改 |

前兩張把「訂單完成」與「已取消」併為同一條唯讀分界，後兩張只認「已取消」一條。

四張卡各自限定的欄位群不同（印件欄位、客戶資料、訂單資訊四區塊、三類備註），所以不必然是直接衝突。但讀者無法從任一張卡判斷「訂單完成之後到底哪些能改、哪些不能」，而 [[明細時點分界]] 只寫明細層、未涵蓋這四個欄位群。

本矛盾來自既有正本，不是本次討論產生。

## 待解答

- [ ] 訂單進入「訂單完成」後，四個欄位群各自能不能編輯，分界在哪一條狀態

## 候選方案

- **A（統一為訂單完成即唯讀）**：四個欄位群一律以終態為界；代價是完成後發現備註寫錯、客戶換聯絡人都改不了，要走其他路徑
- **B（統一為已取消才唯讀）**：完成後仍可改，只有取消才鎖；代價是已結案訂單的金額與印件規格仍可被改動，對帳基準浮動
- **C（分群訂界，逐群寫明）**：金額與印件規格以完成為界、備註與聯絡資料以取消為界；代價是規則變複雜，要有一張卡承載完整對照

不受影響項：訂單異動與售後服務的既有路徑不變，終態後要動金額仍須先開售後服務單。

裁決後要同步的位置：四張情境卡的收斂狀態段與範圍外段、[[明細時點分界]]、[[訂單]] 與 [[印件]] 欄位表的「可否修改」欄。
