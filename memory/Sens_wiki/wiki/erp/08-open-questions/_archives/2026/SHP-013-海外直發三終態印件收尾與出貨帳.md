# SHP-013 海外直發三終態的印件收尾與出貨帳

## 問題描述

[[派單狀態]] 有三個海外直發終態（分批／全出／送大陸客戶），貨不回台、不經場內最終品檢、不走台灣 [[出貨單]]；但 [[印件生產流程]] 的三條印件完成路徑（完全廠內／廠內＋外發／完全外發）終點都是回台品檢入庫再出貨，海外直發是缺席的第四條路徑：

1. 印件的入庫數（＝品檢通過累計）與可出貨額度在貨不回台時如何成立。
2. 印件「已送達」收尾與訂單完成怎麼觸發（無台灣出貨單可依）。
3. 品質責任與驗收憑證由誰承載（大陸客戶簽收？中國廠自檢？）。

## 待解答

- [x] 海外直發路徑的數量帳成立方式 → 不設；本輪不處理海外訂單
- [x] 印件與訂單收尾的觸發來源 → 不適用
- [x] [[印件生產流程]] 補第四條完成路徑 → 不補，維持三條

## 決議（2026-08-01，Miles 拍板）

**EC 海外訂單先當不存在，ERP 只處理台灣 EC 訂單。**海外直發三終態不在本輪範圍：不為它設計印件收尾與出貨帳、不補第四條完成路徑、不新增任何欄位（原提案的「境外交付數量」欄位與平行交付帳一併作廢，判為過度設計）。

三個終態保留在 [[派單狀態]] 的列舉裡，因為現況平台已有這些值（狀態列舉忠於現況事實），但卡內已標註本輪範圍外。派單所有終態的作用只有一個：讓對應 [[生產任務]] 完成報工；印件與訂單的收尾一律走台灣線既有規則（貨回場經揀貨人員點收 → 生產任務完成 → 工單完成 → 印件層最終品檢通過累計入庫 → 出貨單送達）。

範圍依據：`production-stage-high-level-design.md` § 0.2 已宣告不納入 EC 出貨（物流單）整合，海外直發屬 EC 端的交付路徑。**日後要納入海外訂單**（數量帳、品質責任、驗收憑證）時另開新卡承接，本卡不預留設計。

落地去處：[[派單狀態]]（三個終態的說明欄加範圍外標註＋一段註記）。[[印件生產流程]] 維持三條完成路徑、不動。
