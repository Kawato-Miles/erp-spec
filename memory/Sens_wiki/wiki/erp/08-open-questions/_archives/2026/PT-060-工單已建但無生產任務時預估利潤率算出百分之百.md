# PT-060 工單已建但無生產任務時預估利潤率算出百分之百

## 問題描述

[[印件]] 的預計成本＝旗下全部未作廢工單的計價快照彙總。一張工單已建立（草稿或分派後尚未登打製程）但旗下沒有任何生產任務時，彙總為 0，預估利潤率算出 100%。規格只寫「印件小計為空或旗下無工單時顯示破折號」，沒有為「有工單但無任務」設例外，prototype 照實呈現 100%。本問題由 prototype 實作打出，不是既有正本矛盾。

## 待解答

- [x] 有工單但旗下無任何生產任務時，預估利潤率要照算 100%、還是視同預計成本為空顯示破折號？ → 見決議

## 候選方案

- **A（照算）**：規則最簡，100% 就是「還沒登打成本」的訊號；代價是主管掃列表會把它讀成賺很多
- **B（視同空值）**：預計成本彙總為 0 且無任何任務時，預計成本與預估利潤兩欄顯示破折號；代價是多一條判斷

## 決議（2026-09-21，Miles）

**結論**：採 B。有工單但旗下無任何生產任務、預計成本彙總為 0 時，視同預計成本為空：預估利潤與預估利潤率顯示「－」，不算成 100%。

**理由**：100% 不是賺頭訊號，是「還沒登打成本」；主管掃列表會誤讀。

落地去處：[[印件]] 預估利潤欄說明。
