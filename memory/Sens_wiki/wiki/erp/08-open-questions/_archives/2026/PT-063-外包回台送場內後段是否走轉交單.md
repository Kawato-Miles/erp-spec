# PT-063 外包回台的貨送場內後段產線時，走不走轉交單

## 問題描述

外包工序做完、貨回台點收後，要送場內下一道工序時，正本寫法互相矛盾。矛盾來自既有正本。

| 來源 | 寫法 |
|---|---|
| [[轉交單]] 營運背景 | 只寫一條路：生管建目的地為品檢站的轉交單 |
| [[外包與回廠點收]] 主流程與相關段 | 下一站依 [[工序相依性規則]] 兩軌放行，需轉交的看轉交單已點收量，可送後段產線 |
| production-execution spec 場內轉交適用路徑 | 可送後段所在產線 |
| [[場內轉交與修正]] 範圍外 | 外發回廠不走轉交單（指海外回台物流段） |

Miles 2026-09-24 指定：外包回台後的轉交細節本次不處理；原則是外包在工單上也是生產任務，報工與轉交同一套規則。

## 待解答

- [x] 外包回台後送場內後段產線，是否走轉交單（目的地取外包任務的目的站點）？ → 走轉交單，見決議

裁決後要同步的位置：[[轉交單]]、[[場內轉交與修正]]、[[外包與回廠點收]]。

## 決議

走轉交單。外包回來還要在場內續做的貨一樣算轉交，由廠務負責；外包生產任務也是生產任務，以它為來源建轉交單，目的站點不限品檢站、可送場內產線，與場內轉交同一套建單、搬運、點收機制。否決「只轉交到品檢站、暫存區到產線不走轉交單」：照那樣寫，場內後段任務的到料量永遠是 0，報不了工。派單模組還沒處理，原則上用現在的工單流程處理。Miles 2026-11-06 拍板（wiki 正規化第 4B 批 D2）；第 7 批確認本卡已被涵蓋後封存（memory/erp/wiki-normalization-20261104/第7批-待裁決.md § 三 C1）。

落地去處：[[轉交單]]、[[暫存區為系統站點]] 已於第 4B 批改寫；[[場內轉交與修正]]、[[外包與回廠點收]] 隨同批同步。
