# ORD-050 印件層交期成為承諾正本後訂單準時交貨率的取數層級

## 問題描述

2026-09-08 拍板印件持有獨立「訂單交期」欄，訂單單頭「訂單交期」降為參考欄，不再推導任何印件日期。[[北極星指標]] 的訂單準時交貨率現行取「訂單完成日 ≤ 訂單單頭訂單交期」判準時。改後單頭日期不代表任何一件印件的承諾，同單名片承諾 09-05、型錄承諾 09-20、單頭 09-10 時，訂單 09-18 完成會被判不準時，但名片遲交、型錄提前兩件事實都沒被量到。矛盾來自本次設計，不是既有正本。本次設計依範圍紀律不改指標，缺口交本卡裁決。

## 待解答

- [x] 訂單準時交貨率的準時判定改取哪一層？ → 採候選 C，改為印件準時交貨率
- [x] 訂單交期（訂單層與印件層皆為選填）為空時，該訂單算不算進準時交貨率的分母？ → 不計入分子也不計入分母

## 候選方案

- **A（維持訂單單頭）**：判準不動，單頭日期由業務維護為「整單最晚交貨日」；代價：單頭與印件無約束，數字可信度靠人維護。
- **B（改取印件層聚合）**：訂單準時＝旗下每件印件的實際送達日皆不晚於各自訂單交期；代價：指標算法要改、需要印件層送達日欄（出貨單有）。
- **C（改為印件準時交貨率）**：分母改印件數；代價：北極星指標的定義層級變動。

交期欄於 2026-09-08 晚間拍板維持選填、空著不擋不補，因此分母內可能出現無交期可比的訂單，此為第二個待解答的由來。

不受影響項：毛利率與生產績效指標五項不取交期欄。
裁決後要同步的位置：[[北極星指標]] 算法段與取數來源段；若選 B 或 C，[[印件]] 卡欄位表補送達日引用。

## 決議

採候選 C，北極星指標改為印件準時交貨率（2026-09-11 Miles 拍板）。

分子＝該期間內進入「已送達」且該日期不晚於印件預計出貨日的印件數；分母＝該期間內進入「已送達」的印件總數。預計出貨日為空的印件不計入分子與分母。

候選 A 不成立：同一次拍板已刪除訂單單頭的交期欄，A 案的取數來源不復存在。候選 B 不成立：它仍以訂單為單位，一張訂單只要有一件印件沒談定交期就無從判定，分母會大量流失，且無法回答「哪一件遲交」。

採 C 的代價明列：訂單層「整張訂單的承諾是否達成」不再有指標承接，這是拍板時已知並接受的取捨。

印件送達日的取數採狀態轉入日期，不新增欄位，與訂單完成日的取法同構。打樣印件的「已送達」非終態、可重跑，不計入本指標。

落地去處：[[北極星指標]] 的算法段、取數來源段與已知限制段已改寫；[[印件]] 欄位表已補衍生欄「送達日」。後續兩個衍生議題另開 [[ORD-051-印件準時交貨率在大面積留空時的代表性]] 與 [[ORD-052-印件已送達後預計出貨日仍可改寫指標]]。
