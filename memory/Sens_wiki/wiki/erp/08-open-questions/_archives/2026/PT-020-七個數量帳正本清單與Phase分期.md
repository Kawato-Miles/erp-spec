# PT-020 七個數量帳正本清單與 Phase 分期

## 問題描述

生產階段的數量帳三處說法不一致，且壞掉那側的帳沒有落點：

1. **清單不一**：架構卡列七個數量（目標／生產／良品不良品／不良品處置／完工良品／入庫／出貨），[[齊套邏輯]] 正文寫「貫穿六個數量」、守恆鏈只列四項（報工完成數 ≥ 品檢通過累計 ≥ 已出貨數 ≥ 累計送達數）。
2. **報廢數無落點**：全卡未出現報廢數，但 [[生產績效指標]] 折損率的分子取的正是報廢數；報工不良品數、品檢不通過數、報廢數三者的關係與去重口徑歸 [[QC-004-報工不良與品檢缺口取數口徑|QC-004]]，本卡銜接其結論。
3. **Phase 分期未標**：Phase 1 入庫數＝完工良品數（同一個數），[[成品庫存]] 啟用後（Phase 2/3）才分離為兩個數；數量帳定義若不標分期，Phase 1 會出現一個無實體承載的入庫數。
4. **工單層完工良品數欄位去留**：品檢移印件層（2026-07-21 拍板）後，[[工單]] 欄位表的「完工良品數」層級歸屬待定（工單卡已標註引用本卡）。

## 待解答

- [x] 七個數量帳的正本清單與各自定義（含報廢數落點），正本落 [[齊套邏輯]]
- [x] 守恆鏈是否擴充（不良／缺口側入帳，依 QC-004 結論）
- [x] Phase 1 與 Phase 2/3 的分期標註方式
- [x] 工單層完工良品數欄位的去留與印件層帳的對應

## 決議（2026-07-27 Miles 拍板）

依最後討論結果統一，落地如下：

1. **清單正本**：[[齊套邏輯]] § 數量帳與額度公式新增七個數量統一清單表（目標數量／生產數量／良品數・不良品數／不良品處置數／完工良品數／入庫數／出貨數），各數的定義、層級與來源逐項列明；**報廢數落於「不良品處置數」**（補做／客戶照收／報廢三分流），為折損率分子的來源。
2. **守恆鏈**：通過側四段維持不變；缺口側（報工不良品數與品檢不通過數的關係與去重）**不在本次定死**、續掛 [[QC-004-報工不良與品檢缺口取數口徑|QC-004]]。
3. **Phase 分期**：入庫數標註「現階段＝完工良品數（同一個數）、[[成品庫存]] 啟用後才分離，帳的算法不變」。
4. **工單層欄位**：「完工良品數」自 [[工單]] 欄位表移除，品質帳唯一的家在印件層（工單頁不顯示品檢進度，點進所屬印件看）；[[印件]] 補良品數／不良品數／報廢數三個衍生欄位。
5. [[2026-06-13-生產模組架構設計]] 的數量表改為引用齊套邏輯正本、只留階段對照，處置三分流正名為補做／客戶照收／報廢。
