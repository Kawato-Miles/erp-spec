# PT-022 開機費與工作包的歸集口徑

## 問題描述

「一次上機」的成本與工時歸集有三處矛盾或缺口：

1. **開機費雙記**：[[計價快照]] 為生產任務內嵌 1:1、凍結「開機費」；[[工作包]] 卻明定「開機費在工作包層一次算、不逐生產任務重複計」。同一次上機的開機費同時出現在兩層，預計成本會重複計入——快照凍結的是「單價參數」還是「已分攤金額」待定。
2. **報工缺工作包歸集**：同一工作包內多個生產任務各自報工時，運轉設備、停機時數是否以工作包為單位彙總（避免同一次上機的停機被多筆報工重複計入稼動率分母）未定；[[報工紀錄]] 無「所屬工作包」欄位落點。
3. **在製品估值層級矛盾**：[[在製品]] 寫「依工單凍結的計價快照累計」，但快照掛生產任務層、工單只是彙總，凍結層級兩處說法不一致。

## 待解答

- [x] 計價快照凍結內容與工作包歸集的分工（單價參數 vs 已分攤金額）
- [x] 報工的工作包歸集口徑與欄位落點
- [x] 在製品估值的快照掛載層級校正

## 決議（2026-07-27 Miles 拍板，業界調研佐證見 raw 卡）

1. **快照凍參數組**：[[計價快照]] 開機費凍結「整備標準工時＋機台整備費率＋批量假設（本工單單獨上機一次）」，預計金額為衍生顯示值、不是實際帳的比對本體。重複計在定義上消失（預計與實際是兩本獨立的帳）。
2. **實際唯一發生點＝工作包**：[[工作包]] 一次上機一次算，依主檔可設分攤基礎（預設占版面積比；備選版位數比／數量比／平均分攤，各工序可不同）攤回各生產任務。
3. **差異列併批效益**：[[成本差異]] 新增第五個差異維度「併批整備效益」＝各任務快照預計開機費合計 − 工作包實際開機費，帶原因碼（批量結構），與估價估歪分開列示（對應 SAP 批量差異 lot size variance）。
4. **報工歸集**：[[報工紀錄]] 補「所屬工作包」欄位，設備運轉與停機時數以工作包歸集一次、稼動率與 OEE 分母不重複計。
5. **在製品層級校正**：[[在製品]] 估值改依生產任務層快照累計（工單為彙總視角）。

佐證：SAP 凍量價結構＋lot size variance＋聯產當量分攤；D365 估算與實際分離開關＋TCA；印刷業 BHR（整備＝可計費工時×費率）與 gang run 慣例（分攤基礎無統一規範故做成可設參數）；ABC 批次層成本原則。調研全文與 17 條來源見 [[../../../raw/2026-07-27-claude-research-開機費整備成本業界處理|raw 卡]]。
