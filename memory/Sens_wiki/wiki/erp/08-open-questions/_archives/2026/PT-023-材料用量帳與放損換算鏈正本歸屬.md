# PT-023 材料用量帳與放損換算鏈的正本歸屬

## 問題描述

成品數量帳有正本（[[齊套邏輯]]），料端的帳沒有：

1. **料帳平衡公式無正本**：「理論用量＋放損＝實際領用；實際領用驅動庫存扣帳」無任何卡承載；[[物料消耗記錄]] 自陳「放損率折算公式正本在對應 KPI 規則卡」但 [[生產績效指標]] 只有折損率、無料帳平衡公式，指向落空。
2. **兩成分放損的疊加順序未定**：放損分工序層比例性運轉損與設備層固定開機損（2026-07-22 拍板），但兩者疊加的先後與基數未定——固定開機損是加在含運轉損之後的量上，還是先加開機損再乘運轉損比例，算出來的投入量不同。
3. **材料類生產任務目標數量的算法未定**：換算鏈的第三段（預計生產數 → 材料數量）依拼版模數換算，拼版策略與模數算法由 Miles 另行提供參考後補，目前 [[數量換算規則]] 標記「本卡不承載」。
4. **預留鏈斷頭**：[[物料庫存]] 有「預留量」欄位、說明由工單預留時加項，但工單與生產任務皆無預留欄位或動作。
5. 欄位口徑細節（不良品是否計耗料、扣帳時點、理論 vs 實際）歸 [[PT-013-倒扣耗料口徑]]，本卡管正本歸屬與換算鏈。

> 換算鏈本身的三段結構已於 2026-07-30 落卡（[[數量換算規則]] § 規則：部件倍數換算／放損累積換算／材料需求換算），原「缺第三層」的表述已解除；本卡剩下的是疊加順序、材料段算法與料帳平衡公式的歸屬。

## 待解答

- [x] 料帳平衡公式（理論用量＋放損＝實際領用）的正本歸屬卡：[[數量換算規則]]。
- [x] 兩成分放損的疊加順序與基數：先比例、後固定。
- [x] 工單預留的觸發實體與欄位：本階段不做。

## 決議（2026-08-10，Miles 拍板）

三個子題一次拍完；**子題三（材料類生產任務目標數量的拼版模數算法）不隨本卡結案**，另開 [[PT-042-拼版模數算法]] 承接。

1. **料帳平衡公式的正本歸 [[數量換算規則]]**。原本 [[物料消耗記錄]] 自陳「放損率的折算公式正本在 [[生產績效指標]]」，但該卡只有折損率的比率公式、沒有料帳平衡式，這個指向是落空的。改指數量換算規則的理由：料帳平衡是換算鏈第三段（預計生產數 → 材料數量）的收尾，與部件倍數、放損累積同屬換算，本來就該在同一張卡。
2. **兩成分放損疊加＝先比例、後固定**：預計投入 ＝ 目標數量 ×（1 ＋ 工序運轉損率）＋ 設備開機損固定量。驗算（名片 1,000 份、運轉損率 3%、開機損 20 張）：先比例後固定＝1,000 × 1.03 ＝ 1,030，＋20 ＝ 1,050；先固定後比例＝（1,000 ＋ 20）× 1.03 ＝ 1,050.6，進位 1,051。兩者差 1 張，差在開機損要不要再乘一次運轉損——開機損是調機試印當下就廢掉的固定量，那批料不會再經歷一次生產過程，放在乘法外面才符合它發生的時點。
3. **工單預留本階段不做**（子題四）。預留量的意義完全繫在庫存扣帳上（預留是為了讓別張單看得到這批料被佔住），庫存模組沒來之前預留誰也看不到。[[物料庫存]] 卡的骨架與預留量欄位**保留原樣、不動**——該卡自陳為缺口補骨架，動它等於在沒有庫存模組的情況下先定庫存欄位。

欄位口徑細節（不良品是否計耗料、扣帳時點、理論與實際兩欄）見 [[PT-013-倒扣耗料口徑]] 的決議。

落地去處：[[數量換算規則]]（料帳平衡公式與兩成分疊加順序、驗算例子）、[[物料消耗記錄]]（落空指向改指數量換算規則）、[[齊套邏輯]]（材料用量帳的指向）。
