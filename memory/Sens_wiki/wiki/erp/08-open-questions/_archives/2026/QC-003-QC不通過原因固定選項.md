# QC-003：QC 不通過原因（固定選項）欄位與選項清單

## 問題描述

生產階段 to-be 流程草稿原寫「品檢記錄不通過時帶固定選項原因」，但當時的 QC 實體卡僅有通過數量 / 不通過數量，**無「不通過原因」欄位**（對抗式查核抓出草稿越界）。QC 卡其後已退役（2026-07-21），欄位正本改為印件層 [[品檢紀錄]]，該卡「不通過原因（固定選項）」欄位已標註待本 OQ 收斂。

此欄位的價值是「品質數據化入口」：有固定選項原因後，才能統計各主因佔比、各工序 / 各外包不良率、色差 vs 刮傷等分佈，支撐良率細分與外包品質管理，呼應痛點「無法查產能、耗損率」。成本低（QC 記錄多一個下拉欄位）。

## 涉及範圍

- 模組：品檢、生產任務
- 相關卡：[[品檢紀錄]]（欄位正本；原 [[QC]]／[[QC 狀態]] 已於 2026-07-21 退役，品檢改掛印件層）、[[生產任務]]、[[品檢人員]]
- 影響範圍：
  - [[品檢紀錄]] 實體卡「不通過原因」欄位的固定選項清單（欄位正本歸 wiki，該卡已標註待本 OQ）
  - 未來良率 / 不良率 KPI 細分（[[生產績效指標]]）的分組維度來源
  - 與 [[PT-003-NCR Rework 具體實現]]（不良品處置 NCR/Disposition）的銜接（原因 → 處置）

## 部分拍板

- 2026-06-15 Miles 拍板：QC「不通過原因」欄位**要做**，並以業界初版選項先上、後續再改。
- 仍 open：固定選項清單的最終內容（待現場品檢 / 印務收斂）、欄位是單選或可複選、是否每筆不通過數量需各標一個主因。

## 決議（2026-07-31，Miles 拍板）

**品檢一次就一個原因**：不通過原因為固定選項**單選**，一筆品檢紀錄記一個原因；同一批貨驗出多種不良（30 件裡色差 20、刮傷 10）就分批各記一筆，統計自然分得開，不在單筆內做原因拆分計數。

理由：品檢本來就是分次驗、一次驗收一筆，分筆記錄符合現場動作；在單筆內再拆原因陣列等於多一層填寫負擔，現場不會填。

初版選項清單（依不良發生環節分六組：印刷面／表面加工／裁切成型／裝訂／材料／規格數量）已寫入 [[品檢紀錄]] § 不通過原因選項 作為值域正本。**後續誰接住**：欄位值域屬商業決策，現場品檢與印務用起來要增刪就直接改該段，不再另開 OQ；良率細分與外包品質管理的分組維度即以此為來源（見 [[生產績效指標]]）。

落地去處：[[品檢紀錄]]（欄位形態改單選、新增「不通過原因選項」值域段、來源段與相關 OQ 列同步）。

## 候選方案（初版業界選項，待現場收斂）

依不良發生環節分組，作為下拉初版（現場可增刪）：

| 分組 | 固定選項（初版） |
|------|----------------|
| 印刷面 | 色差／偏色、套印不準、糊版／印紋不清、漏印／墨色不均、墨點／油污 |
| 表面加工 | 上光（亮膜／霧膜）起泡或刮花、燙金／打凸位置偏或脫落、局部 UV 偏位 |
| 裁切／成型 | 裁切尺寸不符、裁切／摺線偏移、開孔／刀模位置偏（壓克力、立體件） |
| 裝訂 | 騎馬釘／膠裝／穿線不良、書背歪、頁序錯 |
| 材料 | 紙張／板材瑕疵（紙痕、皺摺、破損）、厚度不符、邊緣崩裂 |
| 規格／數量 | 做錯版本或規格、材質錯誤、數量不足／缺件 |

初版選項先寫入 [[品檢紀錄]] 欄位設計即可運轉（原 [[QC]] 卡已退役）；最終清單待併入生產／出貨現場訪談批次與品檢確認後收斂（external）。
