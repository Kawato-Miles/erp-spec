# PT-068 經分享或延伸看得到工單的人，能否看該工單底下生產任務的歷程與轉交進度

## 問題描述

單據存取範圍卡（已於權責結構重構拆解刪除，可見範圍改由 [[生產單據檢視活動清單]] 承載）定了工單的可見範圍，也定了分享與上下層延伸會讓哪些人看得到工單（分享機制見 [[單據分享與職務代理]]）。卡上沒有寫明這份可見範圍是否涵蓋工單底下生產任務的歷程與轉交進度。

Linear 中台 - 生產管理（PM-1359 轉交進度檢視，以及生產任務歷程相關節）交付時，只開放權限表列出的角色看這兩項，另案寫「待裁」。典型對象是工單分享的檢視成員，以及經訂單往下延伸看得到工單的業務。

這個缺口來自既有正本沒寫，不是本次討論產生的矛盾。

## 待解答

- [x] 經分享或上下層延伸看得到工單的人，看不看得到該工單底下生產任務的歷程與轉交進度？見決議

## 候選方案

- **A（跟著工單）**：看得到工單就看得到這兩項；權限表要補上分享與延伸的對象。
- **B（只限權限表角色）**：維持現行交付，分享與延伸只看工單本身，不含生產任務層的歷程與轉交進度。

不受影響項：生產任務的報工、修正、點收等操作權限不變，本題只問檢視。

裁決後要同步的位置：權責結構重構後的對應活動清單卡（[[生產單據檢視活動清單]]）、Linear PM-1359 與生產任務歷程所在 Feature 票的權限表與另案處理。

## 決議（2026-10-14，Miles）

**結論**：採 A。經分享或上下層延伸看得到工單的人，看得到該工單底下生產任務的歷程與轉交進度。

**理由**：歷程紀錄與轉交進度都是 [[生產任務]] 自己的欄位，看得到生產任務就看得到這兩項；業務經訂單延伸看得到工單詳情內的生產任務已拍板（Sens memory/erp/plans/_archives/2026/document-access-scope-20261013/grill.md G56、G57），兩者一致。B 讓同一個人看得到生產任務卻看不到它的歷程，代理與回覆客戶時要另外求人，否決。

落地去處：
- [[生產單據檢視活動清單]]：既有 ACT-VPRD-044、ACT-VPRD-045（被分享工單）、ACT-VPRD-046（業務、諮詢經自己負責的訂單）、ACT-VPRD-047、ACT-VPRD-048（被分享訂單）已涵蓋，檢視的是 [[生產任務]] OP-TSK-008 檢視生產任務，歷程與轉交進度隨之可見；範圍外段補一句寫明，不另增列
- Linear PM-1359 與生產任務歷程所在 Feature 票的權限表與另案處理：待權責結構重構合回主線後更正（G57）
