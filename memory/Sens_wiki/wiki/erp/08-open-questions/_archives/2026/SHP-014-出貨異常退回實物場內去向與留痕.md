# SHP-014 出貨異常退回實物的場內去向與留痕

## 問題描述

出貨異常（拒收／退件／超商未取）已拍板額度自動回補、退回貨不設系統強制重驗（SHP-010 決議），但退回**實物**的場內處理未定，且與既有拍板可能衝突：

1. 貨回到暫存區要不要走 [[轉交單]] 留痕——「暫存區＝系統站點、貨進出以轉交留痕」（2026-07-20 拍板）與「退回貨不設強制流程」的邊界。
2. 退回貨重出時是否需重驗品檢、由誰決定（現場實務怎麼做要向出貨與品檢現場確認）。
3. 退回貨與報廢的分流判定由誰做。

## 待解答

- [x] 退回實物的入區留痕方式 → 不進系統流程、不走轉交單，見決議
- [x] 重出前是否重驗的現場慣例 → 不強制，由印務個案判斷
- [x] 退回貨報廢的判定者 → 印務

## 決議（2026-07-31，Miles 拍板）

退回**實物不進系統流程**：不走 [[轉交單]] 留痕、不設入區登記，場內由現場人工處理。要重新出貨就**開新出貨單**、原出貨單收於異常或作廢兩終態之一（額度依既有規則自動回補）；重出前是否重驗與退回貨是否報廢，皆由 [[印務]] 個案判斷、系統不設閘門。

與 2026-07-20「暫存區＝系統站點、貨進出以轉交留痕」的邊界因此明確：**轉交單管的是生產流程中的站間流動**，出貨後被退回的貨已離開生產流程，不回頭套用該機制。強制留痕與強制重驗會讓低頻例外變成現場繞過系統的理由；帳面上額度已由異常與作廢自動回補，對得上就夠。

落地去處：[[齊套邏輯]] § 數量帳與額度公式（可出貨額度段補退回實物的處理與重出路徑）。[[出貨單]] 原本已寫「異常統一為終態、重出建新單」，無需修改。
