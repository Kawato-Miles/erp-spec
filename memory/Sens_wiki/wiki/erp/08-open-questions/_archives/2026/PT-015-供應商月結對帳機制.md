# PT-015：供應商月結對帳機制

## 問題描述

供應商對帳現況為印務人工處理；系統方向為以每筆 [[派單]] 的廠商報價資料做月結。月結機制細節未定：對帳週期、執行者、與應付付款的介面、與貨運單運費關稅攤分的關係。

## 待解答

- [x] 對帳週期怎麼定（月結切點、跨月派單歸屬）？ → 見決議
- [x] 執行者是誰：維持印務，或移交會計？ → 見決議
- [x] 與應付付款的介面怎麼接（對帳結果如何轉付款）？ → 見決議
- [x] 與 [[貨運單]] 運費關稅攤分的關係（對帳金額是否含攤分成本）？ → 見決議

## 涉及範圍

- 相關卡：[[派單]]（廠商報價資料承載者）、[[供應商報價規則]]（談價與核價規則，對帳現況段）
- 決定時機：MES／財務設計階段

## 決議

四子題一次拍板（2026-08-04，Miles）：

- **對帳週期與歸屬**：自然月月結；派單以進入終態（台灣已入庫／海外直發交付）的日期歸月，跨月單落在完成那個月，不另定切分規則（與「對帳以撈取終態派單為基準」一致）。
- **執行者與付款介面**：印務每月自派單管理匯出終態派單清單、與廠商帳單核對（印務有談價核價脈絡），整理應付清單交會計執行付款——決定與執行分離，比照退款模式；應付清單人工整理、不建應付模組（系統外明說）。
- **與運費關稅攤分的關係**：分開兩條帳——對供應商只對派單核定報價（帳放 [[派單]]）、對物流商的運費關稅放 [[貨運單]]；攤分只影響內部成本歸集，不混進供應商對帳。

落地去處：[[供應商報價規則]] 對帳段轉定論（含派單管理匯出、決定執行分離、兩條帳分離）；[[派單]] 與 [[貨運單]] 現行欄位即可承載、無需增欄。
