# SHP-024 實際出貨日取最晚離廠後的判定穩定性

## 問題描述

本次設計把出貨單實際出貨日改為「未作廢物流單中最晚的離廠時間」，且只在全部未作廢物流單都已離廠時才有值（Miles 2026-10-20 拍板取最晚）。

這個值會在事後變動：

| 情況 | 實際出貨日怎麼變 |
|---|---|
| 一筆物流單出貨動作失敗，隔天再拋成功 | 從空值變成隔天 |
| 最晚離廠的那筆物流單被作廢 | 改成次晚那筆的時間 |
| 出貨單 X 部分離廠時實際出貨日為空，首張判給 Y；X 的失敗物流單作廢後 X 有值且早於 Y | 首張出貨單改判為 X |

[[北極星指標]] 寫印件準時交貨率取首張出貨單的實際出貨日，且「後續各批不改變已判定的結果」。判定值事後變動，與這句互相牴觸。矛盾來自本次設計與既有正本。Miles 已說明目前 ERP 與 MES 沒有畫面使用這個指標。

範圍宣告：本卡只管準時判定在實際出貨日或首張出貨單認定事後變動時要不要重算。實際出貨日的取法已拍板，不在本卡。

## 待解答

- [ ] 實際出貨日事後變動時，印件準時判定要跟著重算，還是鎖定第一次有值時的結果？

## 候選方案

- **A（跟著重算）**：判定永遠反映當下的實際出貨日；代價是已報告過的準時率可能變動。
- **B（鎖定首次值）**：第一次有值時判定，之後不改；代價是作廢後的判定不反映實際離廠。

不受影響項：實際出貨日的取法；首張出貨單的認定規則（最早全數離廠者）本身不變，但認定結果會隨上表情況變動，一併在本卡裁決。
裁決後要同步的位置：[[北極星指標]] 取數來源；[[出貨單]] 實際出貨日欄。
