# QC-010 計入完成度的生產任務報廢後，待驗量會變負數

## 問題描述

[[QC-009-待驗量基數改取計入完成度任務良品數最小值]] 定待驗量＝各計入完成度任務良品數取最小值 − 已驗量。[[齊套邏輯]] 定報廢任務的良品自印件累計排除（成本留、數量除）。已驗量沒有對應排除。

| 步驟 | 數字 |
|------|------|
| 計入任務 T1 良品 600，品檢通過 600，已出貨 600 | 待驗量 0 |
| 客戶異動，T1 轉報廢，印務加開 T2 目標 400 | 可驗良品數變 0，待驗量 0 − 600＝ −600 |
| T2 報工良品 400 | 待驗量 −200，品檢驗不了 T2 的 400 |

品檢驗收、品檢修正、相關報工修正的檢核都會被負數卡住。

矛盾來自既有正本之間（齊套邏輯的報廢排除與待驗量算式）。

## 待解答

- [ ] 計入任務報廢後，已驗量要不要一併處理？怎麼處理？

## 候選方案

- **A（已驗量依報廢範圍排除）**：報廢任務所屬那一批的已驗量一併排除，品檢紀錄標記為隨報廢失效。代價：要定義已驗量如何對應到哪一筆任務的產出。
- **B（報廢後換新週期）**：比照打樣週期，報廢加開後開新週期，只算新週期的任務與品檢紀錄。代價：已出貨的量要另外接上額度算式。

不受影響項：未報廢的一般情況、打樣週期界線。

裁決後要同步的位置：[[印件]]、[[品檢紀錄]]、[[齊套邏輯]]。
