# PT-062 生產任務的計畫設備與任務預計完成日，在製程核可後、生產中能不能改

## 問題描述

製程核可之後，生產任務的兩個欄位能不能改，各處寫法互相矛盾。矛盾來自既有正本，不是本次討論產生。

| 來源 | 計畫設備 | 任務預計完成日 |
|---|---|---|
| [[印務]] 主要職責「派工排程」 | 任何狀態都可調整 | 任何狀態都可調整 |
| [[工單異動與生產任務調整]] 範圍外 | 屬排程規劃，任何狀態都可調整 | 同左；核可後改晚標「排程超期」 |
| [[生產任務]] 欄位表 | 生產中換機走工單異動 | 印務可改 |
| work-order spec 製程規劃 | 只在工單草稿或重新確認製程時可改 | 同左 |
| Prototype 生產任務表單 | 製程鎖定後不能改 | 製程鎖定後不能改 |

目的站點已於 2026-09-24 另行裁定：任務不是已作廢、報廢都能改。本卡不含目的站點。

不拍板的後果：印務在生產中發現設備或日期要調整時，不知道能不能直接改，還是要走工單異動。手冊的規劃製程頁暫時照 Prototype 寫：鎖定後不能改。

範圍：本卡只管計畫設備與任務預計完成日。工單異動在 Prototype 的補做另有工作線，換機是否走異動與該工作線一併判斷。

## 待解答

- [ ] 製程核可後，計畫設備與任務預計完成日由誰、在什麼條件下可以改，是否要走工單異動？

## 候選方案

- **A（兩欄都屬排程，任何狀態可改）**：照印務卡與工單異動卡。代價是生產任務卡、spec、Prototype 都要改。
- **B（換機走異動、日期可直接改）**：計畫設備照生產任務卡走工單異動；任務預計完成日由印務直接改，核可後改晚照既有規則標排程超期。代價是印務卡、工單異動卡要改，Prototype 要開放日期欄。
- **C（兩欄都鎖，改動一律走異動）**：照 spec 與 Prototype。代價是改日期也要走異動，現場調整變慢。

不受影響項：目的站點的修改規則；需轉交標記的鎖定規則。
裁決後要同步的位置：[[印務]]、[[生產任務]]、[[工單異動與生產任務調整]]；work-order spec 製程規劃 Requirement；Prototype 生產任務表單的鎖定判定。
