# ERP 介面通則（字樣與子母表）

> 定位：ERP Prototype 介面字樣與子母表樣式的通則，適用全部模組。
> 依據：change shipment-print-download-center grill.md G19、G20、G25（Miles 2026-10-23 拍板）。
> 與 wiki 的分工：介面字樣給使用者操作，wiki 操作名稱給規格引用，兩者目的不同、不要求字面相同。業務名詞與操作名稱的正本在 wiki 實體卡。
> 與其他檔的分工：介面業務行為規範見 `ui-business-rules.md`；視覺規範與元件見 erp repo 的 skill `prototype-from-prompt`（本檔不動 erp skill）。

## 一、字樣規則

| 規則 | 內容 | 例 |
|---|---|---|
| 名詞 | 取 wiki 實體卡欄位表與狀態列舉的字面，不簡寫、不自創同義詞 | 「物流單」不寫「托運單」；「可出貨」不寫「待出貨」 |
| 通用動作 | 用通用動詞 | 新增、編輯、刪除、檢視、下載、列印 |
| 業務動作 | 用 wiki 實體卡操作段的操作名稱 | 確認可出貨、撤回確認可出貨、拋單、出貨確認、送達確認 |
| 批次動作 | 「批次＋動作」 | 批次拋單 |
| 對話框標題 | 建立時「建立＋單據名」；檢視時「單據編號＋狀態」 | 建立出貨單；SH-2026-0901 可出貨 |
| 送出鈕 | 文字＝動作名稱，不寫「確定」「送出」 | 對話框為確認可出貨時，送出鈕寫「確認可出貨」 |
| 說明文字 | 新增任何說明文字（欄位提示、區塊說明、空狀態以外的引導句）須先經 Miles 同意 | — |

## 二、子母表

- 母表與子表的巢狀呈現一律使用共用子母表樣式（`@shared/styles/table` 的 nestedTableCss）。
- 子表有自己的表頭；每列可展開；沒有子列時顯示「沒有資料」。
- 適用位置：出貨管理、訂單出貨單頁籤、訂單列表、訂單發票區、需求單詳情；新增子母表一律照此。

## 三、檢查

- erp-prototype-tests 設字樣檢查測試，比對本檔第一節的名詞、動作與送出鈕規則。
- 新增或修改頁面時，依本檔自查後再提交。
