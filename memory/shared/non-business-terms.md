# 非商業術語對照表

非 ERP 業務領域、但常出現在產出中的流程用語與工具詞的核准用法。
商業術語不收（正本在 wiki 各卡一句話定位段與印刷業共用術語表）。
句法規則正本在 `/Users/b-f-03-029/.claude/output-styles/ste100-pm.md`，兩檔搭配使用。
新增判準：一個詞在產出中出現過歧義或被 Miles 反映難懂，就收進來。

| 術語 | 核准用法 | 說明 |
|------|---------|------|
| 稽核 | 保留 | 指 plan-audit、vault-audit 等檢查流程；不寫「審計」 |
| 收斂 | 改寫 | 對話中寫「定案」「整理成單一版本」；「收斂」只用於既有檔名與規範名 |
| 落卡 | 保留 | 指把定案內容寫進 wiki 正本卡；第一次出現給一行說明 |
| 閉環 | 改寫 | 寫「驗證有做完」「頭尾對得上」；閉環屬 PRC 用語 |
| 守衛（guard） | 改寫 | 依 CLAUDE.md 術語對應表：狀態機用「轉換條件」、權限類用「把關條件」 |
| rubric | 改寫 | 寫「評分準則」，需要時括號附註（rubric） |
| delta | 改寫 | 寫「差異」「規格差異檔」，需要時括號附註（delta） |
| archive | 改寫 | 寫「封存」「歸檔」 |
| dispatch | 改寫 | 寫「派工」「派 sub-agent」 |
| 正本 | 保留 | 指唯一權威版本；不寫「單一事實來源」直譯 |
| 消費（consume） | 改寫 | 寫「取用」「只取用、不自行實作」；描述資料流向時寫完整句（誰提供資料、誰拿去呈現、不產生不改寫）。2026-08-20 Miles 反映票文「消費本票提供的資料」讀不懂 |
