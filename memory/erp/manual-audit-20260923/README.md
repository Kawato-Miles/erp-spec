### B. Prototype 缺陷（手冊要寫到的，要先修）

| # | 現象 | 影響 |
|---|---|---|
| B1 | 工作包「調整師傅」改人後按「儲存」拋出例外（取函式的那一行被刪） | 派工頁常見問題引用這個操作 |

| B5 | 品檢站頁首叫人到「轉交單管理」查貨，品檢人員看不到該頁 | 手冊未引用，但品檢人員會困惑 |
| B6 | 其餘小瑕疵：活動紀錄顯示英文「reason：」、轉交單編輯成功訊息提到不能改的目的地、發票空表文字提到不存在的按鈕、資料主鏈鏈一出貨明細與 mock 不一致 | 不影響手冊 |

建議：B1 到 B5 走 prototype 修正（先改 MOCK-DATA-CHAIN、再改 mock、跑測試），修完再定稿對應頁。
