# Wiki 領域 tag 檢索驗收 Golden Set（草稿，待 Miles 確認）

> P4 驗收用（plan `wiki-tag-migration`）。單題判準：**領域判定正確 + 關鍵卡零遺漏 + 不拖入不相關領域的卡**；10 題通過 ≥ 9 題即驗收通過。
> 題目取自 2026-05 至 2026-07 的真實規劃議題（git 歷史與 OQ）。
> 「關鍵卡」＝該次討論若漏載會直接影響設計品質的卡；同領域其他命中卡屬合理載入，不計錯。
> 狀態：**草稿**——Miles 確認或增刪後生效。

## 驗收執行方式

1. 每題以模擬提問跑一次檢索規約（判領域 → tag 查卡名清單 → 比對）
2. 逐題記錄：領域判定、命中清單、關鍵卡命中率、是否拖入不相關領域
3. ≥ 9 題通過 → P4 放行進 P5；未達 → 修 tag／觸發詞後重跑
