## 九、skill 共用骨架與七個 skill 的資料夾計畫（2026-10-29，D16 採乙試行）

### 9-1 「情況對應檔案」是什麼

出處：claude.dev 文章 2 的圖 B。一個除錯用的 skill，SKILL.md 本文放一張表：遇到什麼情況，去讀資料夾裡哪個檔（例：工作卡住讀 stuck-jobs.md、重試風暴讀 retry-storms.md）。原文句：「Tell Claude what files are in your skill, and it will read them at appropriate times.」白話：SKILL.md 是目錄頁，細節放子檔，Claude 碰到那個情況才載入。本計畫改稱「情況對應檔案」。

### 9-2 SKILL.md 共用骨架（所有新 skill 同一格式）

| 段 | 放什麼 | 不放什麼 | 依據 |
|---|---|---|---|
| frontmatter `name` | skill 名 | — | — |
| frontmatter `description` | 什麼時候用（觸發詞、流程時點）、什麼時候不用 | 內容摘要 | cd2「description 不是摘要」 |
| 目標 | 一到三句：做完後有哪些產出、各落在哪 | 背景、來歷 | cd2「只寫目標與限制」；P7 |
| 產出 | 一張表：檔名、落點、誰寫 | — | V5 載體拍板 |
| 限制 | 只放硬規則：不可逆動作、正本歸屬、閘門（缺檔退件）、句法兩檔指名 | Claude 本來就會做的事、逐步作業程序 | cd1「只在重要處加限制」；D5、D6 |
| 順序 | 只列順序不可換的步驟，一行一步 | 每步的做法 | cd2 |
| 情況對應檔案 | 表：情況 → 讀哪個檔 | — | cd2 圖 B |
| 陷阱 | 真實失敗累積，每條一行，附日期與出處（誤判記錄、audit 檔、log） | 推測的風險 | cd2「陷阱段訊號最高」；P4 |

長度：SKILL.md 上限 90 行；`references/` 每檔上限 60 行；超過就再拆檔。門檻值只寫一處（評分準則卡 § 九或該 skill 的一個檔）。

資料夾固定成員：

| 檔 | 用途 | 必有 |
|---|---|---|
| SKILL.md | 目錄頁 | 是 |
| references/<主題>.md | 方法、派工單骨架、表格定義 | 視需要 |
| scripts/<檢查>.py | 機械檢查，結束碼 0 或 1 | 能寫成腳本的檢查都放這裡（P13） |
| CHANGELOG.md | 只追加層，記每次改動與理由 | 是 |
| config.json | 設定值（例如模型、effort 預設） | 只在有設定時 |
