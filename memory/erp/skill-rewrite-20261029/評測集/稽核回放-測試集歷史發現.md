# 測試集歷史稽核發現整理

本檔整理三個案件的歷史稽核評分表。只記稽核檔寫了什麼，不評論缺陷對錯。
基底提交碼 176f10b。量尺版本：規劃品質評分準則最後提交 9039afb。

## 一、記錄規則

| 項目 | 規則 |
|---|---|
| 讀取範圍 | 每個稽核檔的評分表逐列讀。判定為「未通過」「部分通過」（含括號註記，例如「部分通過（依賴 OQ）」）就記錄 |
| 不記錄 | 判定為「通過」「通過（沿用）」「不適用」的列；對抗推演、盲測、核對表、呈報段不是評分表列，不記筆數 |
| 一筆的單位 | 一個非通過列裡的一個缺陷。一列寫了多個缺陷就拆成多筆，一列只有一個缺陷就是一筆 |
| 獨立缺陷 | 同一缺陷跨列、跨輪出現只算一個獨立缺陷，給一個編號（出貨 A-、印件複製 B-、修正統一 C-） |
| 前輪重複判定 | 後輪稽核檔寫明前輪該項「仍」「未處理」「部分」「殘留」，或同一張 OQ 的依賴延續，判「是」。後輪寫明前輪該項「補上」「已修」，再寫出的問題判新缺陷（「否」）。同一輪內他列已記過的缺陷，標「否（同輪）」 |
| 依賴 OQ | 處置或證據寫明依賴未決 OQ，或寫「某題裁決前此行為不得寫 specs／不得進 propose」，判「是」。處置只寫「或開 OQ」這種選項，判「否」 |
| 處置欄 | 照錄稽核檔處置欄原文。一格處置對應多個缺陷時，只照錄對應該缺陷的那一段 |
| 出處 | 稽核檔名＋行號（行號以本基底的檔案為準） |
