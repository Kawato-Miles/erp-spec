## 一、計數規則

| 規則 | 內容 |
|---|---|
| 讀取範圍 | 只讀各稽核檔的「評分表」。復驗表、對抗推演表、缺口核對表、新問題表不計入 |
| 一筆 | 評分表中判定為「未通過」或「部分通過」的一列 |
| 缺陷單元 | 一筆的證據欄常列出多個子缺陷。每個子缺陷編一個單元代號（急件 R-xx、出貨 S-xx） |
| 獨立缺陷 | 以缺陷單元計。同一單元跨輪重複只算一個，記首次輪次與最後出現輪次 |
| 同輪重複 | 同一輪兩列講同一件事實，共用一個單元代號；不算跨輪重複 |
| 前輪重複欄 | 「是」＝該列全部單元在前輪出現過；「否」＝全部是新單元；「部分」＝新舊混合 |
| 依賴 OQ 欄 | 「是－等拍板」＝稽核欄寫明等 OQ 或延後事項拍板；「是－承接缺漏」＝稽核指出 OQ 未開、編號未回填、承接不成立或封存依據不當；「是－僅處置」＝稽核欄未提 OQ，只有主對話處置以 OQ 承接；「否」 |
| 處置欄 | 急件案取評分表處置欄。出貨案第 1、2 輪評分表沒有處置欄，取同檔「主對話處置」表中標到該檢核項的列 |

## 七、第 2 輪以後才首次出現的獨立缺陷

| 判斷值 | 意思 |
