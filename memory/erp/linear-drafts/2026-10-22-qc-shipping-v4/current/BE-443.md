# BE-443 [ Task ] - 出貨單建立與管理的資料操作

狀態：In Progress

---

## 要做什麼

提供出貨單草稿、保密代寄、建立、明細數量修改、作廢、刪除與檢視的資料操作，讓業務與諮詢管理每一批出貨。

（[參考留言](<https://linear.app/sensationdeveloper/issue/BE-443#comment-c79c1556>)）

## 要開的 API

 1. 出貨單列表讀取
 2. 出貨單讀取
 3. 出貨單歷程讀取
 4. 裝箱明細讀取
 5. 物流單讀取
 6. 物流單歷程讀取
 7. 草稿預設帶入讀取
 8. 出貨方式讀取
 9. 建立出貨單草稿
10. 編輯出貨單
11. 建立出貨單
12. 修改出貨明細數量
13. 作廢出貨單
14. 刪除出貨單草稿
15. 訂單取消的出貨單連鎖處理
