## 概述

這張票做完，揀貨人員能在 <project id="2ba2439d-73c6-426c-a384-af08eafb815d" href="https://linear.app/sensationdeveloper/project/%E4%B8%AD%E5%8F%B0-%E5%93%81%E6%AA%A2%E8%88%87%E5%87%BA%E8%B2%A8-555eb8966074/overview">中台 - 品檢與出貨</project> 依出貨單開始揀貨、逐條回報揀貨數量、逐箱回報裝箱資料，並修正填錯的裝箱回報。

出貨單的狀態流轉見 <project id="2ba2439d-73c6-426c-a384-af08eafb815d" href="https://linear.app/sensationdeveloper/project/%E4%B8%AD%E5%8F%B0-%E5%93%81%E6%AA%A2%E8%88%87%E5%87%BA%E8%B2%A8-555eb8966074/overview">中台 - 品檢與出貨</project> 的出貨單狀態機。

>>> ## 開始揀貨

身為揀貨人員，我要按開始揀貨，以讓業務看得到倉庫已在處理這張單。

**實體關係**

1. 出貨單即揀貨指令。揀貨人員依單清點入庫的成品。
2. 開始揀貨寫入出貨單歷程。

**驗證規則**

1. 出貨單在未處理才可開始揀貨。

**驗收**

1. 假設承品檢驗收建立的 ORD-2026-0820 出貨單處於未處理。當揀貨人員在列上按「開始揀貨」並確認，則狀態由未處理轉打包中，歷程多一筆「開始揀貨」。

>>> ## 完成裝箱回報

身為揀貨人員，我要逐條回報揀貨數量、逐箱回報箱規、長寬高與照片，以讓裝箱結果與每箱大小留在單上。

**實體關係**

 1. 揀貨數量逐條記在出貨明細，不預填。
 2. 裝箱資料逐箱記錄，一箱一筆，記箱規、長寬高、裝箱照片與裝箱備註。
 3. 一箱可有多張裝箱照片。裝箱備註選填。
 4. 裝箱資料不記每箱裝了哪些印件與各幾個。
 5. 箱序為三位數，不重排。
 6. 箱規從全部箱規或「自訂」擇一。所有出貨方式共用同一套箱規。
 7. 選「自訂」時，箱規記「自訂」，不指向任何一筆箱規。
 8. 箱規記名稱與長寬高，單位公分。沒有量過的尺寸留空。箱規如下：

| 箱規 | 長 | 寬 | 高 |
| -- | -- | -- | -- |
| F12 箱 | 15 | 11 | 4.5 |
| N3 箱（3 號箱） | 30 | 15 | 15 |
| F13 箱 | 29 | 21 | 6 |
| K1 箱 | － | － | － |
| MIX 箱（新 Mix 散件） | 35 | 25 | 15 |
| 300 拼圖箱 | 35.5 | 45.5 | 4.5 |
| 1 號箱 | 45 | 30 | 15 |
| 感官箱 | 32 | 24 | 36 |
| 馬克杯箱 | 50 | 45 | 36 |
| 1000 拼圖箱（地墊箱） | 80 | 55 | 7.5 |

 9. 每箱各存一份長寬高。箱規日後改尺寸，已存的值不變。
10. 長寬高依箱規欄的選擇帶入，完成裝箱回報與裝箱回報修正都一樣：

| 箱規欄的選擇 | 長寬高 |
| -- | -- |
| 選一筆箱規，含改選另一筆箱規 | 照該箱規的長寬高帶入，不可改。箱規沒記的欄位空白 |
| 選「自訂」 | 空白，選填手填 |
| 從一筆箱規改成「自訂」 | 保留原值，可修改 |

11. 完成裝箱回報時，系統依「支援子母單」屬性產生物流單：

| 支援子母單 | 產生物流單的方式 |
| -- | -- |
| 是 | 全部箱子合成一筆物流單 |
| 否 | 一箱一筆物流單 |

12. 物流單編號是出貨單編號加三位序號。一張出貨單至多 999 筆物流單。
13. 揀貨數量與出貨明細數量不符時，揀貨人員照實填，並現場通知業務。
14. 揀貨人員不自行改明細。系統不發通知，也不設異常回報。
15. 瑕疵或找不到的量，照實填揀貨數量。處置在系統外協調。
16. 任一條出貨明細的揀貨數量不等於出貨數量，即為揀貨不符。

**驗證規則**

1. 出貨單在打包中才可完成裝箱回報。
2. 每條明細的揀貨數量必填。
3. 至少一箱。每箱的箱規必填，至少一張裝箱照片。
4. 漏填時不受理，出貨單不推進。
5. 選一筆箱規時，長寬高必須等於該箱規記的值，箱規沒記的欄位必須空白，不符時不受理。
6. 揀貨不符不擋裝箱回報。出貨單照常轉已裝箱。
7. 完成裝箱回報、裝箱回報修正與編輯出貨單修改明細數量，會搶同一張單的揀貨不符判定。
8. 兩筆同時寫入時，先寫入者成立。後到者以寫入當下的數字重新判定，檢核不過時不寫入，系統告知卡住它的原因。

**驗收**

1. 假設承品檢驗收建立、已開始揀貨的 ORD-2026-0820 順豐出貨單。當揀貨人員在「裝箱回報」逐條填揀貨數量，再按三次「新增一箱」，每箱選箱規並各附一張照片後送出，則出貨單轉已裝箱。每條明細有揀貨數量，裝箱明細有三箱，三箱合成一筆物流單。歷程多一筆「裝箱回報」。
2. 假設承品檢驗收建立、已開始揀貨的順豐出貨單。當揀貨人員漏填揀貨數量就送出，則對話框不關閉，單不推進。補填後把裝箱明細全部移除送出，則提示「至少要有一箱」。新增一箱只選箱規、不附照片送出，則提示「至少要附一張裝箱照片」。三種情形單都留在打包中。補齊後送出，則轉已裝箱。
3. 假設承品檢驗收建立、已開始揀貨的出貨單明細 500。當揀貨人員把該條明細的揀貨數量填 470 並送出，則出貨單照轉已裝箱。警示訊息列出該條明細的揀貨與出貨差異，並說明不符未解除前不能執行出貨動作。列表在狀態旁標「揀貨不符」。
4. 假設承品檢驗收各建一張順豐單與 7-11 交貨便單，各出 100。當揀貨人員各逐箱新增三箱送出，則順豐三箱合成一筆物流單，編號為出貨單編號加 -001，三箱同屬這一筆。7-11 交貨便三箱各成一筆物流單，編號加 -001、-002、-003，每箱各屬自己的物流單。另開一張 7-11 單與一張順豐單的裝箱回報，則兩張的箱規選項相同，列出全部箱規：F12 箱、N3 箱（3 號箱）、F13 箱、K1 箱、MIX 箱（新 Mix 散件）、300 拼圖箱、1 號箱、感官箱、馬克杯箱、1000 拼圖箱（地墊箱），最後一項為「自訂」。
5. 假設承品檢驗收建一張新竹物流單、一張全家單與一張專車配送單，各出 100，皆已開始揀貨。當揀貨人員在新竹物流單新增一箱選「1 號箱」，則長寬高帶入 45、30、15 且不可改，送出後裝箱明細顯示 1 號箱與 45、30、15。在全家單新增一箱選「K1 箱」並附照片送出，則長寬高照箱規空白且不開放填寫，空白不擋下，送出後箱規為 K1 箱、長寬高無值。在專車配送單新增兩箱都選「自訂」，第一箱填 60、40、30、第二箱留空送出，則兩箱箱規都記「自訂」，第一箱為 60×40×30，第二箱長寬高無值。繞過畫面對 1 號箱送出不同的長寬高，或對 K1 箱送出任何長寬高，則系統不受理。

>>> ## 裝箱回報修正

身為揀貨人員，我要修正填錯的裝箱回報，或改掉被物流商拒收的那一箱，以讓出貨單的裝箱資料與現場一致。

**實體關係**

1. 修正直接改原值，不改出貨單狀態。
2. 可修正明細的揀貨數量，以及新增箱、修改箱與刪除箱。修改箱時可改箱規、長寬高、裝箱照片與裝箱備註。
3. 修改箱規時，長寬高依完成裝箱回報節的帶入表調整。
4. 修正後至少保留一箱。
5. 新增或刪除箱時，系統依拆單規則調整物流單：

| 支援子母單 | 新增箱 | 刪除箱 |
| -- | -- | -- |
| 是 | 併入該筆物流單 | 從該筆物流單移除這一箱 |
| 否 | 產生一筆新物流單，序號接在最大值之後，不重用 | 系統直接刪除該箱的物流單，不走作廢 |

6. 出貨單屬部分離廠時新增箱，只會發生在不支援子母單的出貨方式。新箱產生一筆新的已裝箱物流單，出貨單狀態不變。
7. 每次修正，每個被改的欄位新增一筆裝箱回報修正紀錄。
8. 紀錄記修正前後值、修正人、修正時間與修正原因。修正裝箱照片或刪除箱時，被換掉或刪掉的照片留在紀錄。
9. 修正寫入出貨單歷程，帶前後值與原因。

**驗證規則**

1. 各修正項目在下表條件成立時才可執行：

| 修正項目 | 可執行條件 |
| -- | -- |
| 揀貨數量 | 出貨單屬未出貨動作 |
| 刪除箱 | 出貨單屬未出貨動作 |
| 新增箱 | 出貨單在已裝箱 |
| 修改箱 | 該箱所屬物流單在已裝箱 |

2. 已離廠或已作廢物流單底下的箱不可修正，保留為裝箱紀錄。
3. 出貨單離開未出貨動作之後，撤掉一箱改走作廢物流單，見 PM-1401。
4. 修改箱選一筆箱規時，長寬高必須等於該箱規記的值，箱規沒記的欄位必須空白，不符時不受理。
5. 修正原因必填，未填無法修正，不改任何欄位。
6. 修正後，系統重新判定本單的揀貨不符。
7. 修正與出貨動作同時寫入時，先寫入者成立。後到的修正以寫入當下的條件重新檢核，含不可修正的項目時整筆不受理。系統告知卡住它的原因，如本單已有物流單離廠、該箱不能再修正。

**驗收**

1. 假設承品檢驗收自建一張新竹物流出貨單，出貨數量 500。揀貨人員已回報揀貨數量 480、裝箱 2 箱，單在已裝箱、物流單都沒有離廠時間。當揀貨人員按「修正」，把揀貨數量改為 500、新增一箱並選箱規、附照片後送出，則：
   * 先不填修正原因送出時，對話框不關閉，不改任何欄位。
   * 填修正原因再送出，揀貨數量與裝箱明細更新，每個被改的欄位各留一筆裝箱回報修正紀錄，歷程多一筆「裝箱回報修正」帶前後值與原因。
   * 新增的箱產生一筆新物流單，序號接在最大值之後。
   * 出貨人員對第一筆物流單拋單成功後，揀貨人員列上仍有「修正」。修正對話框中揀貨數量不可改、沒有移除箱的鈕，第一筆物流單底下的箱整列鎖住，第二、三筆底下的箱可改，「新增一箱」仍在。
2. 假設兩張新竹物流出貨單各出 100，揀貨人員已各回報揀貨數量 80，業務已把第一張的明細數量改為 80。當揀貨人員把第二張的揀貨數量修正為 100，則第二張兩數相符，「揀貨不符」標籤消失。
3. 假設承品檢驗收建一張順豐單，揀貨人員裝 2 箱，這筆物流單拋單時物流商回傳錯誤。當出貨人員按「拋單」失敗，則揀貨人員列上仍有「修正」。揀貨人員把兩箱箱規改成另一種箱規並填修正原因，出貨人員再拋單成功，則揀貨人員列上沒有「修正」。
4. 假設承品檢驗收建一張 7-11 交貨便單，出 100，裝 4 箱都選「1 號箱」。出貨人員批次拋單後，第 1、2、4 筆轉等待出貨，第 3 筆被物流商拒收、停在已裝箱，出貨單在已裝箱、屬部分離廠。當揀貨人員把第 3 箱改成「F13 箱」、新增第 5 箱並選箱規、附照片、填修正原因送出，則：
   * 修正對話框中揀貨數量不可改、沒有移除箱的鈕，第 1、2、4 箱整列鎖住，只有第 3 箱可改，「新增一箱」仍在。
   * 送出後第 3 箱長寬高重新帶入 29、21、6。
   * 修正紀錄有第 3 箱箱規、長、寬、高各一筆，與新增第 005 箱一筆。
   * 系統產生第 5 筆物流單 -005，在已裝箱。
   * 第 1、2、4 筆物流單與揀貨數量不變，出貨單維持已裝箱，箱數為 5。
   * 全部離廠後，揀貨人員列上沒有「修正」。
5. 假設承品檢驗收建一張 7-11 交貨便單，出 100，三箱都選「1 號箱」並完成裝箱回報。當揀貨人員以裝箱回報修正把第一箱改成「F13 箱」、第二箱改成「K1 箱」、第三箱改成「自訂」，填修正原因送出，則第一箱帶入 29、21、6 並鎖住，第二箱帶入空白並鎖住，第三箱保留 45、30、15、可修改。修正紀錄中第一箱與第二箱各有箱規、長、寬、高四筆，第三箱只有箱規一筆。
