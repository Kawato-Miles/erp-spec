## 要做什麼

提供需求單複製、分享與接單業務改派的資料操作，讓業務從過往需求單起手並分享給同事，業務主管在人員異動時換接單業務。

## 要開的 API

1. 需求單複製
2. 分享成員清單讀取
3. 分享成員新增
4. 分享成員層級修改
5. 分享成員撤銷
6. 接單業務改派

## 不用自己做

* 改派理由分類與離職交接清空分享成員的處置：由 PM-1086 提供。
* 需求單與印件項目的讀取與寫入：由 BE-26 提供。
