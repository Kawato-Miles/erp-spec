範圍用詞只有六個：全公司（檢視）、全公司（編輯）、自己負責、被分享（檢視）、被分享（編輯）、所屬產線。

| 訂單 | 接單業務 |

上下層延伸通則：上層單據的自己負責者與被分享者，也能看到下層單據；被分享的層級沿用上層（S3）。看哪個模組就用哪個模組的範圍（S5）。

## 定案的範圍用詞

| 用詞 | 定義 |
|---|---|
| 全公司（檢視） | 該模組全部單據，只能查看 |
| 全公司（編輯） | 該模組全部單據，可做負責人能做的事，含管理分享、跨單取消；動作記在本人名下 |
| 自己負責或建立 | 該單據的負責人是本人（各模組看的欄位見總註二） |
| 所屬訂單為自己負責 | 該單據所屬訂單的接單業務是本人 |
| 被分享（檢視） | 以檢視層級分享給本人且未撤銷，只能查看 |
| 被分享（編輯） | 以編輯層級分享給本人且未撤銷；不論角色，可做負責人能做的事，含管理分享 |
| 所屬產線 | 單據的產線在本人的所屬產線內（只用於生產相關模組） |
| 指派給自己 | 單據的指派對象是本人（生產的指派師傅、負責廠務；審稿的指派審稿人員；派單的指派廠商） |

範圍外：欄位或頁籤層級的可見性不寫進 wiki，另案處理。
