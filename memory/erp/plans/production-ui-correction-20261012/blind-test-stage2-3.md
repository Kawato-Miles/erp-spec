# 生產管理與工單第二、三段盲測題目（草案，待 Miles 確認）

## 第二段：wiki → Linear

受測者只讀 Linear 草稿（memory/erp/linear-drafts/2026-10-13-production-workorder-v7/），答案要與 wiki 一致。

| # | 題目 | 標準答案（wiki） | 出處 |
|---|---|---|---|
| 1 | 印務已把生產任務交付產線，但生管還沒接收，也還沒打包進工作包。師傅能對這筆任務報工嗎？ | 能（若前置到料量大於 0）。報工前提是已交付，不要求接收或打包 | 報工規則 |
| 2 | 一筆任務有兩個前置任務，到料量分別是 600 與 400。這筆任務的到料量是多少？到料量為 0 時能報工嗎？ | 400（多前置取最小）；為 0 時擋下報工 | 工序相依性規則 |
| 3 | 師傅在我的生產任務能修正別的師傅提交的報工嗎？能修正自己提交、但任務已改派給別人的報工嗎？ | 都不能。我的生產任務只能修正與作廢自己提交、且在該入口報工範圍內的報工；改派後由所有生產任務或所有工作包的使用者修正 | 報工規則 |
| 4 | 生管在所有生產任務可以修正哪些報工？ | 所屬產線範圍內的全部報工 | 報工規則、單據存取範圍 |
| 5 | 外包廠的生產任務報錯了，生管能在所有生產任務修正嗎？ | 不能。外包廠與中國廠商任務不在所有生產任務與所有工作包，只能經工單詳情修正與作廢（本批另案） | 報工規則 |
| 6 | 一次報工修正把良品 500 改 480、不良品 0 改 20，系統留幾筆修正紀錄？修正原因必填嗎？ | 兩筆（每個被改的欄位一筆）；修正原因必填 | 報工紀錄 |
| 7 | 已完成的生產任務（目標 1,020），唯一一筆報工被作廢，累計歸 0。任務會變成什麼狀態？ | 待處理 | 生產任務狀態 |
| 8 | 已完成的任務能再新增一筆報工嗎？報錯了怎麼辦？ | 不能新增；錯誤用修正原有報工 | 報工規則 |
| 9 | 生產任務良品 1,000、搬運量 600、點收量 500。轉交可申請上限是多少？轉交進度怎麼顯示？ | 上限 400（良品數 − 搬運量）；轉交進度為搬運量 600、點收量 500 兩數，不含良品 | 生產任務 |
| 10 | 收貨人點收時，點收數量多於搬運數量，系統會擋下嗎？ | 不擋，照收 | 轉交單狀態 |
| 11 | 點收錯了一整筆（不該存在），要用修正還是作廢？ | 作廢點收紀錄（數字錯才用修正） | 轉交單狀態、報工紀錄 |
| 12 | 工作包要換師傅，怎麼做？取消工作包在哪個單元？取消後報工怎麼辦？ | 在所有工作包取消工作包後重新打包；報工留在任務上不受影響 | 工作包、印件生產流程 |
| 13 | 兩個人同時寫入會影響同一印件待驗量的操作（例如報工修正與品檢驗收），系統怎麼處理？ | 先寫入者成立，後到者以寫入當下的數字重新檢核 | 報工規則 |
| 14 | 工單詳情生產任務表的轉交進度欄顯示什麼？ | 搬運量／點收量兩個數字 | 生產任務 |

通過條件：3 位受測者每題結論都與標準答案一致。

## 第三段：Linear → 開發設計

受測者 3 位扮演後端、3 位扮演前端，只讀 Linear 草稿與開發看得到的 wiki、Prototype。

| 角色 | 題目 |
|---|---|
| 後端 | 列出你要開的 API（每支寫用途一句），以及你會回頭問 PM 的問題 |
| 前端 | 列出你要做的頁面與控制元件（動作按鈕、對話框、側板、頁籤），每項寫要接哪個資料操作，以及你會回頭問 PM 的問題 |

通過條件（Miles 判定）：
- 後端列出的 API 涵蓋各 Feature 權限表的每一列動作。
- 前端列出的控制元件涵蓋各 Task 票的清單。
- 3 位之間沒有互相矛盾的設計。
- 「會回頭問 PM 的問題」逐條檢查：屬於票上缺資訊的，回頭修票；屬於規範範圍外的，不算缺。
