# 設計（去論證版）：生產與出貨的修正機制、數量欄、出貨明細揀貨

只含規則、流程與數字。

## 修正

修正＝對一筆已存在的回報紀錄改值；必填修正原因；系統留修正紀錄（修正欄位、修正前、修正後、修正人、修正時間、修正原因）。數字錯用修正，整筆不該存在用作廢。

| 回報紀錄 | 可修正欄位 | 作廢 |
|---------|----------|------|
| 報工紀錄 | 生產數量、良品數、不良品數、備註 | 有 |
| 點收紀錄 | 點收數量、備註 | 有 |
| 轉交明細 | 搬運數量（開始搬運後） | 只能作廢整張轉交單 |
| 品檢紀錄 | 通過數量、不通過數量、不通過原因、品檢照片（可補可換，至少一張） | 無 |
| 裝箱回報 | 出貨明細的揀貨數量、每箱幾個；出貨單的箱數、箱規、裝箱照片 | 無 |

## 品檢紀錄修正

- 執行者：品檢人員，在品檢站。
- 上限：修正後該筆通過＋不通過 ≤ 本筆原通過＋本筆原不通過。新到的量一律新增一筆驗收。
- 通過下限：修正後該印件通過累計 ≥ 該印件所有未作廢、非異常出貨單的出貨明細數量合計。
- 不通過下限：修正後不通過累計 ≥ 已報廢類處置數量＋補做已承接數量。
- 一筆一個不通過原因；修正時選主要原因；不通過改 0 時原因清空。
- 修正紀錄保留修正前照片；原紀錄標「已修正」。
- 命中即整筆擋下。
- 揀貨發現瑕疵：揀貨人員照實填揀貨數量（不符）→ 揀貨人員通知業務 → 業務轉印務 → 印務判定瑕疵後業務改出貨明細數量 → 印務請品檢人員修正改判不良。
- 印務決定照收不通過的量：品檢人員修正，把不通過改為通過。
- 待驗量＝齊套良品數 − 通過累計 − 不通過累計。

## 單元操作

| 單元 | 操作 |
|------|------|
| 所有生產任務 | 報工；報工修正、報工作廢（任務子層逐筆、生產任務側板）；派工、手動完成等 |
| 我的生產任務 | 報工；修正與作廢自己提交的報工 |
| 所有工作包 | 報工；報工修正、作廢；編輯、取消工作包 |
| 我的工作包 | 報工；編輯工作包；修正與作廢自己提交的報工 |
| 所有轉交單 | 建單、編輯（待搬運）、作廢、重開、開始搬運、抵達站點；點收、點收修正、點收紀錄作廢（母層轉交單列）；搬運數量修正（子層明細列） |
| 點收佇列 | 點收、點收修正、點收紀錄作廢（母層） |
| 我的轉交單 | 開始搬運、抵達站點 |
| 工單詳情 | 報工；生產任務側板報工修正與作廢（工單負責人、取得編輯分享的成員） |
| 品檢站 | 驗收、品檢修正 |
| 出貨單（揀貨人員） | 開始揀貨、裝箱回報、裝箱回報修正（限待出貨） |
| 出貨單（出貨人員） | 第三方：拋單、下載物流單；專車：出貨確認；自取：交付確認；送達確認、異常 |
| 出貨單（業務，建單人） | 建草稿、建立出貨單、編輯（未離廠三態只改明細數量）、作廢、刪草稿 |

角色預設單元：師傅＝我的生產任務、我的工作包、點收佇列；品檢人員＝點收佇列、品檢站；生管、印務、印務主管＝所有生產任務、所有工作包、待轉交任務、所有轉交單、點收佇列；廠務＝我的轉交單；Supervisor＝五個「所有」單元唯讀。所有 X 單元的範圍依使用者所屬產線。

報工修正與作廢的既有擋下條件不變（改完不得跌破下游已用量、不得讓待驗量為負等）。已完成任務因修正或作廢使生產數量累計跌破目標數量且大於 0 時退回製作中。各入口的修正範圍＝該入口的報工範圍。

併發：品檢驗收與修正、出貨單建立與增量、裝箱回報與修正、拋單或出貨確認，先寫入者成立，後到者以當下數字重新檢核。

## 生產任務數量

- 搬運量＝未作廢轉交明細的搬運數量合計。
- 點收量＝各轉交明細有效點收紀錄的點收數量合計。
- 轉交可申請上限＝良品數 − 搬運量。
- 轉交進度顯示「搬運量／點收量」。
- 到料量：需轉交前置取前置點收量；不需轉交前置取前置良品數；多前置取最小；到料量 0 擋報工。

## 出貨單

| 層級 | 欄位 |
|------|------|
| 單頭 | 出貨單編號、訂單、客戶、出貨方式、預計出貨日、實際出貨日、收件人、電話、地址、寄件資訊、裝箱指示、備註、建單人、物流單號 |
| 包裝 | 箱數、箱規、裝箱照片、重量 |
| 出貨明細 | 印件、數量、揀貨數量、每箱幾個（合箱時＝該印件在一箱佔幾個） |
| 裝箱回報修正紀錄 | 修正欄位、前、後、修正人、時間、原因 |
| 歷程 | 建立、編輯、開始揀貨、裝箱回報、裝箱回報修正、拋單或出貨確認、交付確認、送達確認、異常、作廢、狀態變化 |

狀態：草稿 → 未處理 → 打包中 → 待出貨 → 運送中 → 已送達；自取由待出貨直接到已送達；異常、已作廢為終態。

- 開始揀貨：未處理 → 打包中。
- 裝箱回報（揀貨人員逐條填揀貨數量、每箱幾個，填箱數、箱規、照片）：打包中 → 待出貨。
- 待出貨期間可裝箱回報修正，不改狀態；運送中以後不能修正。
- 任一條揀貨數量 ≠ 數量即「不符」。不符未解除前擋下拋單、出貨確認、交付確認，列表標示不符。解除：業務改明細數量，或揀貨人員裝箱回報修正揀貨數量；業務亦可作廢。
- 揀貨數量不預填，揀貨人員逐條填。
- 第三方拋單：出貨人員選填重量；寫入實際出貨日；物流單號由物流商回傳；可下載物流單；待出貨 → 運送中。
- 專車出貨確認時出貨人員選填重量，確認後可補填。
- 作廢、異常回補可出貨額度。
- 可出貨額度＝通過累計 − 出貨明細佔用合計。
