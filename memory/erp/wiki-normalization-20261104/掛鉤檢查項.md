# 掛鉤檢查項（草案，待 Miles 核對）

錯誤：擋下，寫檔後退回代理、提交前拒絕提交。警告：回報給寫入者逐筆判讀，不擋。
門檻值（例如逐字重複的最短字數）只寫在規範卡一處，本檔不寫數字。

| S5 | 連結指向的卡存在；`[[卡名#標題]]` 的標題存在 | 錯誤 | G3；Obsidian 不報標題斷鏈 | 新增 |

## 三、不進掛鉤、留給定期深度稽核

| 項目 | 理由 |
|------|------|
| 頁面間矛盾 | 要讀懂兩邊內容，機器只能列候選 |
| 撰寫規範 L2、L3 勾稽 | 段落職責是否分離要判讀 |
| 欄位名是否為概念詞 | 稽核誤判記錄顯示機器常判錯 |
| 能力問題驗證 | 每批遷移收尾時跑（G9） |
