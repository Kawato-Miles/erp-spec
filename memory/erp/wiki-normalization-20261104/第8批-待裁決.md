### 七之二、寫入檢查跳過草稿卡的寫法（等主對話核准）

原則：草稿卡的內容還沒定案，不檢查內容正規化；格式、連結、放置位置照樣檢查，以免草稿卡把結構弄亂。

| 檢查 | 草稿卡 | 理由 |
|------|-------|------|
| S1 卡頭必填與值域 | 照樣檢查 | 格式不分定案與否 |
| S2 相對引用、行號引用、簡體字、寫死數量 | 照樣檢查 | 語言與引用格式 |
| S4 待確認措辭、問題框 | 照樣檢查 | 不確定項一律開待裁決問題卡，草稿也一樣 |
| S5 連結對象存在 | 照樣檢查 | 斷鏈任何卡都不該有 |
| S6 正本卡連到封存卡 | 照樣檢查 | 同上 |
| S16 資料夾與領域標籤一致 | 照樣檢查 | 放置位置 |
| X3 卡名唯一 | 照樣檢查 | 結構 |
| S14 詞彙表格式 | 照樣檢查 | 只針對詞彙表本身 |
