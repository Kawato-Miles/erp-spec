標準工廠和我們的差別，用一本 500 本的 A5 精裝書來看

左邊是製造業教科書的做法，右邊是 wiki 目前的設計。每張卡下面一條「商業影響」：誰會痛、哪個流程、哪個指標。

1. 接到單，要記四張紙。我們記了兩張半

標準工廠

銷售訂單客人要 500 本
→
品號A5 精裝書 200 頁；書芯；封面；道林紙 80g
→
BOM 與路線1 本＝1 書芯＋1 封面；書芯用 N 張紙加 3% 損耗
→
工單500 本 × BOM ＝ 領幾令紙

品號是中心。訂單指它、BOM 掛它、工單也掛它。

我們現在

訂單＋印件規格、製程說明、數量、進度十一欄全寫在印件
→
無成品與半成品品號只有材料、工序、裝訂、設備主檔
→
印件配方、部件配方工序段：印刷→摺紙→配頁→鎖線；用量倍率只作參考
→
工單＋生產任務數量、放損由印務逐筆手填

少了品號。配方有步驟沒份量。每張工單的數字都是人填的。

商業影響

誰痛業務（回頭單重填規格）、印務（每張工單重算數量）、會計與 PM（算不出單一產品的毛利與良率）
哪個流程成交轉訂單、工單製程規劃、EC 整合（Phase 3）
哪個指標產品毛利、產品良率：算不出。Phase 1「BOM 覆蓋率」：只量到步驟展開，沒量到用量展開
何時會痛回頭單比例上升時；EC 整合要把規格品對到 ERP 時

2. 書印好了，放哪裡？

標準工廠

完工回報良品 500
→
待驗庫存一個庫存狀態，不能出貨
→
品檢分流合格入庫；重工開單；報廢過帳
→
成品倉入庫單；在庫多少才能承諾多少

每走一步，書就換一個庫存狀態。架子和倉是系統裡真的存在的東西。

我們現在

報工紀錄生產數量、良品數、不良品數
→
待驗量印件層算出來的數
→
品檢紀錄通過 495、不通過 5；缺口處置兩軸
→
可出貨額度又一個數；貨留品檢區

沒有架子、沒有倉。能出幾本是算出來的數字，不是倉裡真的有幾本。

商業影響

誰痛出貨人員與業務（分批交、客戶自取、要補貨時找不到貨在哪）、品檢（退回重驗沒有單據）、會計（報廢只有數量沒有金額）
哪個流程品檢通過入庫、出貨與送達、售後補做；EC 規格品若要備貨，整段無載體
哪個指標庫存紀錄準確率：算不出。折損金額：算不出。可承諾量只在印件層成立
何時會痛單批完工即出貨時不痛。分批入庫、退貨重驗、跨訂單調撥、EC 備貨時開始痛

3. 客人在網站勾尺寸、紙張、裝訂

標準工廠

勾選項
→
可配置品號一個母品號、多種變化
→
超級 BOM 自動挑行勾什麼就選哪幾行、哪幾道工序
→
工單自動長出

網站與工廠共用同一份產品定義。

我們現在

題目與選項選項已綁 ERP 的紙、工序、裝訂、設備識別碼
→
無母品號訂單明細帶規格 JSON
→
EC 商品人工建 BOM與 ERP 配方各一份
→
EC 工單＝PDF工廠照紙本做

前半段（勾什麼）已經做好。後半段（勾了怎麼做）靠人，而且兩邊各寫一份。

商業影響

誰痛EC 商品管理（改一個選項要同步兩邊）、印務（線上單仍要人工對 PDF 排製程）、PM（Phase 1 指標無法由 ERP 算出）
哪個流程EC 商品上架、線上單自動建工單、成本估算
哪個指標EC 規格品 BOM 覆蓋率：分子要由 EC 側人工認定。線上線下同商品成本一致性：無法驗證
方向差業界網店整合把產品與價格的正本放 MIS（即 ERP）端、網店只讀；現行把 EC 商品劃在 ERP 範圍外。這條要在 EC 整合設計前先裁

4. 驗出 5 本有色差，怎麼辦？

標準工廠

重工單另開單或原單加工序；成本可分開看
報廢單數量移到報廢地點，成本入廢料帳

重工多少、報廢多少錢，報表直接看。

我們現在

補做在原工單加任務任務狀態轉「補做」；成本混在原單
報廢數只是處置紀錄的數字
客戶照收＝改品檢紀錄把不通過改成通過

缺口會補回來，但重工成本、報廢金額、原始不良數都看不到。

商業影響

誰痛會計與 PM（重工率、折損金額沒有數字）、品檢主管（照收後原始不良事實只留在修正紀錄）
哪個指標重工率、重工成本、報廢成本：算不出。良率可算，但「照收」會把良率往上修
何時會痛要算真實毛利、要對外包廠或機台比良率時

5. 商業影響總表

差距受影響角色受影響流程算不出或失真的指標發生時點嚴重度
無成品與半成品品號業務、印務、會計、EC 商品管理成交轉訂單、EC 整合、成本歸戶產品毛利、產品良率、回頭單比例Phase 3 開始；回頭單增加高
用量不驅動工單印務、PM工單製程規劃、Phase 1 驗收BOM 覆蓋率失真、用量差異無對照Phase 1 驗收；印務人力吃緊高
待驗與入庫是數字不是狀態出貨、品檢、業務品檢入庫、出貨、售後庫存紀錄準確率、可承諾量只到印件層分批、退貨重驗、EC 備貨中
EC 與 ERP 製法兩套EC 商品管理、印務商品上架、線上單建工單線上線下成本一致性、覆蓋率分子EC 改規格時；Phase 1 驗收高
重工在原單、報廢無金額會計、PM、品檢主管補做、缺口處置重工率、重工成本、折損金額算真實毛利時中
料帳空白（撥料、投料、消耗）印務、採購、會計備料、成本結算實際料耗、材料折損率要算真實毛利時中
BOM 與路線合卡印務、系統設計配方維護、EC 配置對接無直接指標對接 EC 配置器時低
不追蹤貨的實際站點廠務、生管轉交、找貨找貨時間（未量）產線與站點變多時低

嚴重度判準：高＝擋住已排定的 Phase 目標或讓既有 KPI 失真；中＝特定情境才痛、現況有人工繞法；低＝成本可控、可延後。

6. 接下來的三條路（由輕到重，可分階段）

一

寫明邊界，不動結構

把「待驗為衍生數只適用單批完工即出貨」「不追蹤貨位」「補做不開新單」寫進規則卡的適用範圍。風險都還在，但變成已知。動三張卡，不需裁決。

二

補品號層，其餘不動

成品與半成品品號，印件引用品號，配方對映到品號下的 BOM 與路線；EC 規格品先建。解掉「無品號」與一半的「兩套製法」。要先裁決品號範圍與 Phase 1 指標改寫。

三

品號、用量驅動、成品批

路線二之外，用量倍率幫工單預填（可改），待驗改成成品批狀態，成品庫存最小集合提前到 Phase 2。解掉前四個高中風險。代價是推翻 10 月「系統不預填」拍板、成品庫存提前。

待補兩段

背景知識與實務利弊：品號策略、BOM 與路線分合、待驗庫存狀態、配置器維護成本、重工開單方式、指標依賴關係。研究代理查證中，查完存 raw 後補進本頁。
