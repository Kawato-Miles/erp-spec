# 交期命名收斂

## Why

### Background

交期鏈上一輪（archive `2026-09-11-delivery-date-chain-alignment`）把承諾日下沉到印件層，但名稱留了四個：需求單單頭「訂單交期」、訂單單頭「訂單交期」、印件「訂單交期」、印件「預計交期」，另有訂單層「內部製作截止日」。四個名字指三種語意，讀單的人要靠層級才分得出哪個是對客戶承諾、哪個是內部節奏。

Miles 2026-09-11 拍板十五條，把名稱收斂成兩個：印件「預計出貨日」（對客戶承諾的交貨日）與印件「內部完成日」（內部該做完的那一天），並刪掉需求單與訂單兩層的單頭交期欄與訂單層的內部製作截止日欄。

wiki 已於同日落卡 28 張正本卡，欄位表與狀態列舉的正本在 wiki：

- [印件](../../../memory/Sens_wiki/wiki/erp/05-entities/印件.md)（預計出貨日、內部完成日、送達日三欄）
- [訂單](../../../memory/Sens_wiki/wiki/erp/05-entities/訂單.md)（訂單交期與內部製作截止日兩欄已刪，保留審稿前／審稿後預計出貨日）
- [需求單](../../../memory/Sens_wiki/wiki/erp/05-entities/需求單.md)（單頭交期欄已刪，印件項目改「預計出貨日」逐列手填）
- [工單](../../../memory/Sens_wiki/wiki/erp/05-entities/工單.md)（預計交期改名「內部完成日」，預計完工日不動）
- [生產任務](../../../memory/Sens_wiki/wiki/erp/05-entities/生產任務.md)（預計完成日超期提示規則本體）
- [北極星指標](../../../memory/Sens_wiki/wiki/erp/01-products/北極星指標.md)（訂單準時交貨率停用、改印件準時交貨率）
- [訂單領域資料結構總覽](../../../memory/Sens_wiki/wiki/erp/05-entities/訂單領域資料結構總覽.md)（本次新建）

本 change 把上述已定案的商業層設計同步進 OpenSpec 的系統行為規格。

### Problem Statement

五份既有 spec 仍以舊名撰寫 Requirement 與 Scenario，與 wiki 正本不一致：

| 模組 | 不一致之處 |
|---|---|
| order-management | 印件兩欄仍叫訂單交期與預計交期；訂單單頭訂單交期與內部製作截止日仍有完整 Requirement 與恆定約束；訂單列表仍提供交期篩選；新增與加開印件仍寫「預設帶入訂單的訂單交期」 |
| quote-request | 單頭訂單交期欄與其預填到印件列的規則仍在；印件項目欄名未改 |
| work-order | 工單「預計交期」未改名；紙本單據表頭取數敘述用舊名 |
| prepress-review | 待審清單排序鍵與母子列顯示欄仍用舊名；訂單母列交期欄取數層級未改 |
| production-overview | 待排區顯示「印件交期」與「建議開工日」，後者的交期倒推決議已被推翻 |

另有一項系統行為在本次新增：生產任務的預計完成日晚於所屬工單的內部完成日時，系統軟提示、不擋存檔。

## What Changes

### 命名對照

| 舊名（所在層級） | 新名 |
|---|---|
| 印件「訂單交期」 | 印件「預計出貨日」 |
| 印件「預計交期」 | 印件「內部完成日」 |
| 工單「預計交期」 | 工單「內部完成日」 |
| 需求單印件項目「訂單交期」 | 需求單印件項目「預計出貨日」 |
| 需求單單頭「訂單交期」 | 刪除 |
| 訂單單頭「訂單交期」 | 刪除 |
| 訂單「內部製作截止日」 | 刪除 |
| 工單「預計完工日」 | 不改名 |
| 訂單「審稿前／審稿後預計出貨日」 | 不改名 |

資料語意不變，算式維持：內部完成日 ＝ 預計出貨日 − 1 曆日 − 急件選項凍結天數，以曆日計、無行事曆。

### New Capabilities

無。

### Modified Capabilities

- **order-management**：印件兩欄改名（推導 Requirement 與留痕同步 Requirement 皆改標題，採 REMOVED ＋ ADDED）；訂單列表移除交期篩選與交期起訖區間；「內部製作截止日定義」整節移除，連帶移除其四個 Scenario；成交轉訂單改為只帶印件層預計出貨日；新增印件與加開印件的預計出貨日改為無預設值、空白手填；訂單資訊 Section 移除訂單交期與內部製作截止日兩個編輯入口；印件詳情頁工單區塊、印件急件選項、訂單階段印件規格編輯時機、製作後規格異動通知四處的欄名與引用同步改名。
- **quote-request**：單頭訂單交期欄刪除，印件項目「訂單交期」改名「預計出貨日」並改為逐列手填無預填；成交轉訂單改為單層帶入。
- **work-order**：工單「預計交期」改名「內部完成日」（含紙本單據表頭與工單排程日期取數表）；新增生產任務預計完成日超期軟提示的 Requirement。
- **prepress-review**：待審清單排序鍵與空值規則改名；待審訂單模組母列的交期欄與距交期天數欄改取旗下未收斂印件最早的預計出貨日（唯讀衍生、不存欄），子列改「預計出貨日與內部完成日並列」；打樣 NG 複製新印件的保留欄位清單正名為預計出貨日。
- **production-overview**：待排區顯示欄由「印件交期」正名為印件的內部完成日，同行的「建議開工日」移除。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- order-management：印件預計出貨日與內部完成日命名、訂單單頭兩欄移除、訂單列表交期篩選移除、新增與加開印件無預設值。
- quote-request：需求單單頭交期欄移除、印件項目預計出貨日逐列手填、成交轉訂單單層帶入。
- work-order：工單內部完成日命名、生產任務超期軟提示。
- prepress-review：待審清單與待審訂單模組的排序鍵與顯示欄命名、訂單母列交期取數改印件層最早預計出貨日。
- production-overview：待排區顯示欄命名與建議開工日移除。

## Impact

- wiki：28 卡已落（2026-09-11），本次不再改動。
- OpenSpec：五份 main spec 的規格差異檔（delta）。
- 北極星指標改印件準時交貨率（拍板 14）由 wiki 承載，openspec 無對應條文可改，本 change 不產生對應 delta。
- Prototype（erp repo `(prototype)`）：需求單印件列、訂單資訊分區編輯、新增與加開印件 Dialog、印件詳情兩交期欄、工單交期顯示與紙本單據、審稿待審清單與待審訂單模組、工廠總覽待排區、工單詳情任務列表超期標示。
- 測試（Sens repo `erp-prototype-tests`）：一、四、五、八、九、十五章的情境與 mock 主鏈同步，欄名全面改寫。
- 接受全鏈可能無交期值（拍板 12）：需求單、訂單、印件三層皆無必填交期欄，預計出貨日為空時內部完成日同為空、工單內部完成日同為空、審稿排序落到最後、超期提示不比對。本 change 不加任何緩解。
- 後端差異走 Linear 另案處理，不在本 change 範圍：訂單 `deadline` 與內部製作截止日兩欄的停用、需求單單頭交期欄停用、印件兩欄改名的欄位對映。
