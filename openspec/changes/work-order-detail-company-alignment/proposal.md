# 工單詳情頁對齊公司參考文件

## Why

### Background

公司 2026-09-18 交來三份參考文件（工單詳情頁調整欄位對照表、調整內容 Prototype、ERP 日期欄位架構定義與算法 v3）。Miles 於 2026-09-20 的 grill 十三題與 pre-check 十題逐題拍板，設計方案經 plan-audit 復審全過，wiki 已於 2026-09-21 落卡（commit 20b5150、c11d01c）。本 change 只把已定案的商業層內容同步進 OpenSpec 的系統行為規格，不重跑釐清。

商業層正本：

- [印件](../../../memory/Sens_wiki/wiki/erp/05-entities/印件.md)（印件屬性改名、四個利潤欄與其可見範圍、規格備註與包裝備註的可改角色）
- [工單](../../../memory/Sens_wiki/wiki/erp/05-entities/工單.md)（確樣需求欄、工單審核主管改名、摘要兩個利潤率的取數、紙本表頭）

### Problem Statement

wiki 已改，OpenSpec 還停在舊用詞與舊行為，兩邊對不起來的有下列各處：

| 模組 | 不一致之處 |
|---|---|
| sales-platform | 印件詳情頁的成本區塊寫「毛利率只對印務主管與 Supervisor 顯示」，與印務可見利潤率的拍板相反；仍用舊名毛利率；沒有報價與利潤頁籤 |
| work-order | 生產任務「實際開工日」寫成生管分派當天寫入，與報工規則既有的「以第一筆報工為動工事實」互相矛盾；確樣需求只是紙本沿用的欄目、不是正式欄位；工單類型的帶入來源仍寫印件類型；工單成本仍分預估成本與成本對照兩處；工單的「審核主管」欄名未改 |
| quote-request | 印件項目仍算毛利率；需求單的「印件類型」（27 值）與印件層的「印件屬性」（2 值）同名異義 |
| production-overview | 五指標列「毛利率」，算式的分母寫「售價」，與 wiki 的小計口徑不一致，且未拆預估與實際兩組 |
| order-management、order-adjustment、consultation-request、order-billing | 六份 spec 仍寫「負責業務」 |
| prepress-review、qc | 仍寫「印件類型」 |

另有三件事系統現在做不到：印務在工單頁看不到這一件還剩多少賺頭；工單上沒有地方記確樣方式，現場只能看手寫紙本；印務在工單頁改不了印件的規格備註與包裝備註，只能請業務改。

## What Changes

### 命名對照

| 舊名（所在層級） | 新名 | 例外 |
|---|---|---|
| 毛利率（全庫） | 利潤率 | [BOM結構](../../../memory/Sens_wiki/wiki/erp/04-business-logic/營運規則/訂單到交付/BOM結構.md) 的「毛利率加成」是定價法名稱、對應後端計價引擎參數，照舊不改 |
| 印件「印件類型」 | 印件屬性 | 值域打樣與大貨不動 |
| 需求單「印件類型」（27 值） | 需求品項類別 | — |
| 「負責業務」（全庫） | 接單業務 | 「負責業務主管」是「負責＋業務主管」，不在改名範圍 |
| 工單「主管」 | 工單審核主管 | 其餘「主管」的角色泛稱不動 |
| 生產任務「實際開工日」 | 任務實際開工 | — |
| 工作包「確樣需求」 | 確樣備註 | 與工單新開的「確樣需求」是不同欄位 |

### 行為變更

- **利潤呈現**：印件詳情頁新增「報價與利潤」頁籤，取代原成本區塊，列七欄未稅金額（印件小計、預計成本、實際成本、預估利潤、預估利潤率、實際利潤、實際利潤率）；不列稅額與含稅金額。預估利潤率與實際利潤率各依三段門檻（35% 以上、20% 至 35%、20% 以下）標示，只標示、不擋任何動作。
- **可見範圍**：成本三項（預計成本、實際成本、成本對照）對印務、印務主管、Supervisor 可見；利潤四欄另加業務與業務主管，該兩角色看利潤不看成本兩欄，業務只看自己所負責印件。現場角色、訂單管理人、諮詢、會計不可見，不可見時整塊不出現。
- **工單摘要卡**：任務進度與顏色費用合計兩格換成預估利潤率與實際利潤率，取所屬印件口徑。
- **工單成本**：只留成本對照一個頁籤，預估成本頁籤移除。
- **工單確樣需求**：新增十值多選欄（新版、舊版、留版、暫保版、改版、底片、數位樣、機上樣、雷射樣、看印），負責印務與編輯（代理）成員可改、工單非終態可改，製程規劃時填、製程審核時可見、隨紙本工單印出。
- **工單詳情顯示**：印件基本資訊新增接單業務、訂單類型、客戶編號三項衍生顯示；標題列案名為衍生顯示；新增「工單聯絡」唯讀欄，取負責印務的聯絡電話，紙本表頭同取此欄。
- **印件備註可改角色**：規格備註與包裝備註加開給負責該印件任一張非終態工單的印務與其編輯（代理）成員，訂單非終態為前提；稿件備註維持業務或會員；預計產線由印務維護。工單詳情提供印件備註側板、依角色鎖欄。
- **任務實際開工**：改取首筆報工時間，系統寫入唯讀；分派日不再寫入。報工作廢對本欄的處置沿用既有的報工作廢規則，本 change 不新設。
- **廠客引用對位**：訂單與需求單的客戶欄引廠客主檔，顯示客戶名稱與客戶編號。派單指派供應商引廠客（廠商身分外包）或中國供應商帳號、派單刪毛利率欄、貨運單中國供應商欄引中國供應商帳號三項，在 OpenSpec 無對應條文（dispatch-order spec 沒有供應商主檔挑選與毛利率的 Requirement），只落在 wiki 欄位層，本 change 不產生對應規格差異檔。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- sales-platform：印件詳情頁新增報價與利潤頁籤並改寫可見範圍、印件總覽用詞改印件屬性。
- work-order：新增確樣需求欄、摘要卡兩個利潤率、工單詳情的印件與聯絡資訊顯示；任務實際開工改取首筆報工；成本只留對照頁籤；印件層成本彙總口徑寫明；工單審核主管與印件屬性改名。
- order-management：訂單客戶欄引廠客；規格備註與包裝備註加開給印務並定義兩處編輯入口；接單業務與印件屬性改名。
- quote-request：需求單客戶欄引廠客；利潤率與需求品項類別改名；接單業務改名。
- production-overview：利潤率改名、分母統一為小計、四式改引 wiki。
- order-adjustment、consultation-request、order-billing：接單業務改名。
- prepress-review、qc：印件屬性改名。

## Impact

- wiki：已於 2026-09-21 落卡（commit 20b5150、c11d01c），本 change 不再改動。
- OpenSpec：十份主 spec 的規格差異檔。
- 與尚未歸檔的三個 change 有重疊 Requirement：`delivery-date-naming-convergence`、`work-order-visibility-and-sharing`、`fix-order-print-item-actions`。重疊處的基準文字取用與歸檔順序見 design.md。
- Prototype（erp repo `(prototype)/`）：工單詳情摘要卡與成本頁籤、工單資訊區的確樣需求、印件備註側板、印件詳情頁的報價與利潤頁籤、mock 資料（客戶編號 MBC000006、人員聯絡電話）、權限純函式。
- 測試（Sens repo `erp-prototype-tests/`）：見 tasks.md § 測試影響清單。
- 後端另案：廠客主檔的欄位對映、派單毛利率欄停用、人員聯絡電話欄，走 Linear 處理，不在本 change 範圍。
- 主 spec 內兩處在 Requirement 之外的殘留用詞（production-overview 檔頭的指標列、order-management § Data Model 的實體關聯總覽），規格差異檔改不到，歸檔時一併手改（見 tasks.md）。
