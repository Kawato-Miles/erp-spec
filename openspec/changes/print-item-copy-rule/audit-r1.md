## ⑤ 矛盾查證結論

| 項目 | 結論 |
|---|---|
| 是否屬實 | 屬實。[[訂單]] L119 商品小計算式為 sum(印件.小計)，沒有取數範圍；同卡 L62 急件標注、L93 訂單內部完成時間、L129 與 L131 兩個利潤欄都限「旗下有效印件（印製維度非已棄用）」。打樣 NG 新印件帶入單價與購買數量（wiki 與 Prototype 皆然），Prototype 金額導出也確實把已棄用原印件加進去 |
| 性質 | 正本缺口，不是單純漏寫算式。沒有任何卡規定已棄用印件的小計該不該向客戶收。取消製作（OP-PI-019）同樣轉已棄用，客戶可能仍要付已投入的部分；打樣 NG-稿件問題的根因在客戶稿件，重打樣是否另收費也沒有正本（[[打樣流程]] L38 只寫打樣費用掛在訂單） |
| 是否本案造成 | 否。現況 wiki 與 Prototype 已是如此 |
| 本案應如何處置 | 不在本案自行裁決。依 oq-manage mode B 開獨立 OQ 卡交 Miles 裁決。裁決若走「新印件不帶單價」或改帶其他值，等於 G4 之外的第二個例外，需回 grill；裁決若走「商品小計排除已棄用印件」，屬訂單卡算式修改，可另案或併本案由 Miles 決定。OQ 拍板前，打樣 NG 重建對訂單金額的影響不寫進本案 specs 驗收條目 |
