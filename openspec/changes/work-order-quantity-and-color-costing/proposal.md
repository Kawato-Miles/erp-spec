印刷業的工單本來就寫「要交 600 車、放 20 車」。放損緩衝是規劃當下就決定的投入量，不是事後補的差額。目標數量若不定義成投入口徑，備料量與成本輸入都算不出來。色數是平版計價的主要驅動因子，登記不到就系統性低估成本（[PT-038](../../../memory/Sens_wiki/wiki/erp/08-open-questions/_archives/2026/PT-038-色數與特殊色登記口徑三方不一致.md) 已封存）。

### Problem Statement

現行 OpenSpec 與 Prototype 有六個口徑落差：

1. **目標數量語意未定**：投入或產出沒有明文。印件層另有推導欄「預計投入量」講同一件事，兩處各算一次。開機損落在件層時備料會短少（52 對 75 張的算例）。
2. **放損率在任務層沒有載體**：`recipe-expansion` spec 宣稱「印務在製程規劃時可逐張調整」，但欄位正本查無此欄，宣稱落不了地。
3. **完成判定三處衝突**：wiki 齊套邏輯寫「完成數量以產出為準」、報工規則寫「累計達標即完成」、外發報工不填生產數量。同一筆任務算不算做完有兩種讀法。
4. **色數段的顯示條件綁錯對象**：現行條件是「工序型 且 設備有色數模式 且 生產單位類別＝自有工廠」。後果有兩個——外發印刷工序永遠登記不了色數；色數必須先選設備才填得了，但幾色、哪些色不隨設備變。
5. **工序費與設備費的關係未定**：Prototype 有「依設備計價」這個計價方法值，工序費與設備費被做成二選一。印刷工序既有工序費也有設備費時（1,000 ＋ 400 ＝ 1,400）算不出來。
6. **數位設備的特殊色算法與計價引擎不一致**：Prototype 對數位設備乘特殊色倍率，計價引擎的數位是查特殊色面價、不乘倍率。同一台機在兩個系統算出兩個價。

落差的後果：備料短少要現場臨時補料、外發印刷成本低估、印刷任務的成本構成答不出來。

## What Changes

### 數量口徑

- 生產任務目標數量的語意定為**投入計畫**（場內工序與裝訂任務含放損緩衝），系統沿工序相依鏈自末端倒推帶預設值、印務可改（**BREAKING**——語意與取數皆變）。
- 外發任務套**同一條公式**，差異放資料不放規則：外發工序的主檔預設放損率維護為 0。
- 材料型任務目標數量的基數改取**首道場內工序任務目標數量**（該數已含下游累積放損），固定開機損只加在張層（**BREAKING**）。
- 生產任務新增「放損率」欄，工序主檔預設帶入、任務上可調；材料與裝訂主檔無預設值時帶 0。
- 印件「預計投入量」欄與其顯示**移除**（**BREAKING**）。

### 完成判定與警示

- 任務完成判定依變體分工（**BREAKING**）：場內工序與裝訂＝生產數量（投入）累計 ≥ 目標；材料＝報工即完成；外發＝產出累計 ≥ 目標。
- 「製作中 → 已完成」新增手動觸發：**生管手動完成**，供放損低於預期時收尾；僅生管可操作、歷程紀錄留痕。
- 報工超量警示門檻改取**目標數量**（**BREAKING**——原取「目標數量 ×（1 ＋ 放損率）＋ 開機損」，該預留已內含於目標）。
- 生產任務已完成後，該任務的報工作廢 SHALL 被系統擋下；更正走既有人工程序。

### 色數與成本

- 工序主檔新增「是否印刷類工序」旗標（印務維護、預設否），色數段的顯示條件改取此旗標（**BREAKING**——不再看設備與生產單位類別）。
- 色數值域定為五選項：單黑、CMYK、Pantone、金屬色（合印）、獨立印（**新增獨立印**）；印務手選、系統不自動判定、逐項相加不擇一。
- 外發印刷工序可登記色數，純記錄、不參與計價，設備費照實顯示 0。
- 任務成本的構成明文為**工序費（依工序自身計價方法，可為 0）＋ 設備費（開機費 ＋ Σ 色價 × 倍率）**；不新增「依設備計價」計價方法值，Prototype 現行該值於實作階段廢除（**BREAKING**）。
- 設備費的特殊色計價依設備類型分流：平版乘三顆倍率（特別色／金屬／獨立印）；數位三類共用特殊色面價、不乘倍率；大圖無色數概念（**BREAKING**——數位算法改變）。
- 設備主檔的三顆倍率欄標明僅平版適用，「金屬色最低色數」正名為「獨立印倍率」。

### 不在本次範圍

拼版模數代算、自動排程、比價選機、幅面防呆、時間與工時估算、印件結構化成品尺寸欄、材料與裝訂主檔補放損率——全數另案（[PT-042](../../../memory/Sens_wiki/wiki/erp/08-open-questions/PT-042-拼版模數算法.md) 承接拼版段）。

## Capabilities

### New Capabilities

（無）

### Modified Capabilities

- `work-order`：目標數量的投入口徑與倒推預設、放損率欄行為、色數登記的顯示條件與五選項、任務成本構成與特殊色分流、數量邊界防呆與異動重算的取數改寫。
- `production-execution`：報工超量警示門檻改取目標數量、任務完成判定依變體分工、生管手動完成的轉換與把關、已完成任務擋下報工作廢。
- `process-master`：工序主檔提供「是否印刷類工序」旗標，與計價方法脫鉤、改旗標不回溯既有任務。
- `equipment`：印刷計價參數的三顆倍率限平版適用、數位特殊色查表不乘倍率。
- `recipe-expansion`：配方展開的目標數量與放損來源改用同一條倒推公式，材料公式基數改取首道場內工序目標數量。
