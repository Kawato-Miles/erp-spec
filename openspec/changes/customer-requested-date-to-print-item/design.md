# 設計說明

## Decisions

- D1 欄位只搬層，語意與軟提示行為不變；提醒比對對象由「旗下最晚印件預計交期」改為「同一件印件的印件預計交期」，只是把比對範圍縮到自己。
- D2 需求單印件不加此欄（與急件欄同理，需求單階段不談收件日）。
- D3 工單詳情頁與印件詳情頁共用印件基本資訊面板，兩頁同步顯示訂單預計交貨日期與客戶指定收件日，皆唯讀；訂單預計交貨日期取訂單層既有衍生函式，不另算。

## Risks

- mock 資料鏈的 customer_requested_delivery_date 由訂單物件搬到印件物件，改動順序固定：MOCK-DATA-CHAIN.md → 各模組 mock-data.js → 測試。
