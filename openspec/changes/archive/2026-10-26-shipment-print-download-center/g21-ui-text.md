# G21 出貨介面說明文字對照表（2026-10-23）

來源：原 grill 對話第 21 題，Miles 回覆「先用 A」＝照表 A、B、C 處理。下方三表照原文謄錄。
同場預設做法（Miles 回覆「可以」）附在第四表。
注意：表內提到的「已裝箱」「已離廠」是當時的舊狀態名；實作時一律依新模型（可出貨、未離廠）與 Sens `memory/shared/ui-wording.md`。

## A. 建議刪除

| 位置 | 現有文字 | 改成 |
|---|---|---|
| 出貨單單頭的欄位標籤，共 6 個 | 「收件人（建立出貨單時必填）」等 | 只留欄位名稱，必填用星號 |
| 單頭 | 「寄件資訊（依訂單的帳務公司帶出）」 | 寄件資訊 |
| 單頭 | 「裝箱指示（選填；未填時揀貨依公版箱規判斷）」 | 裝箱指示 |
| 單頭、裝箱表 | 「備註（選填）」 | 備註 |
| 裝箱表欄名 | 「裝箱照片（至少一張）」 | 裝箱照片，加必填星號 |
| 裝箱回報對話框 | 「已離廠或已作廢物流單底下的箱不能修改……請由業務作廢物流單。」 | 刪除；不能改的列直接唯讀 |
| 批次拋單對話框 | 「失敗的物流單停在已裝箱，錯誤訊息不另保存……」 | 刪除 |
| 送達確認、作廢物流單 | 「逐印件未送達數量（選填；沒有少送就維持 0）」等兩則 | 改成區塊標題「未送達數量」 |
| 物流單頁籤 | 「寄件人：……」 | 刪除 |
| 訂單出貨單頁籤 | 兩則長說明：訂單已終態時有沒有可出貨額度 | 刪除；建立鈕依條件顯示或隱藏即可 |
| 空表格文字 | 「還沒有裝箱明細：按『新增一箱』加入」「尚未裝箱回報，還沒有物流單」等 | 統一用元件預設的「沒有資料」 |
| 成功訊息，約 15 則 | 「已標記例外；出貨單狀態依物流單轉『異常』，之後可……」等 | 統一格式「已＋動作名稱」，例如「已標記例外」 |

## B. 保留，並縮短文字（元件庫的警示框或訊息樣式）

| 位置 | 類型 | 文字 |
|---|---|---|
| 建立出貨單：按建立後有欄位未填 | 錯誤警示框 | 「尚缺 N 項：」加上可點擊的欄位名稱（維持現況） |
| 出貨單：揀貨數量與明細不符 | 警示框 | 「揀貨數量與出貨明細不符：印件名稱」 |
| 出貨單：有印件已棄用 | 警示框 | 「已棄用印件：印件名稱」 |
| 作廢物流單：這是最後一筆物流單 | 警示框 | 「作廢後出貨單一併作廢」 |
| 修改出貨明細：數量全部改成 0 | 警告訊息 | 「至少保留一筆出貨明細」 |
| 表單欄位未填 | 欄位錯誤文字 | 「必填」（維持現況） |
| 系統擋下的動作 | 錯誤訊息 | 顯示擋下原因（維持現況） |

## C. 這次新增功能會出現的文字

| 位置 | 類型 | 文字 |
|---|---|---|
| 按下列印後 | 成功訊息 | 「已加入下載中心」 |
| 下載中心異常內容欄 | 表格內容 | 「物流單編號：錯誤訊息原文」，每筆一行（G10） |

## 同場預設做法（Miles 回覆「可以」）

| 項目 | 做法 |
|---|---|
| 訂單出貨單頁籤 | 拿掉外框，比照訂單項目頁籤 |
| 對話框寬度 | 依表格欄寬加總設定，表格不橫向捲動，表頭不換行 |
| 列印鈕位置 | 出貨管理列表上方，只對出貨人員顯示；沒有勾選時按鈕停用，不加說明文字 |
| 每次列印筆數上限 | 由後端定 |
| 托運總表欄位 | 照 EC；ERP 沒有的欄位留空 |
