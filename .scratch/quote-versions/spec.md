# 規劃單：需求單多版本報價

- 分級：結構性（新增實體報價版本；新增需求單與報價版本等關聯）。
- 盤點：`precheck.md`；拍板紀錄：`grill.md`。設計方向依 Salesforce 商機與報價單模型，內容以公司規則為主（grill Q8）。

## Problem Statement

客戶常要比較幾套方案（換紙材、改數量、改加工），標案客戶還要同一案拿到兩到三份不同金額的報價。現行需求單只有一組印件項目，業務只能反覆改單價，前一套方案就被蓋掉。

現行正本把標案比價放在訂單層：在訂單上改單價、依訂單當前內容逐份產出報價單（原 [[訂單成立確認]] 副流程、[[報價單取訂單當前內容]]）。比價發生在客戶還沒成交的階段，訂單卻要先建立，還要停在「報價待回簽」反覆改。需求單階段也沒有任何可給客戶的文件（原 [[輸出活動清單]]「需求單沒有輸出操作」）。

## Solution

在需求單下新增「報價版本」，每個版本有自己的印件項目、金額與方案報價單。每張需求單至少一版，建單時系統自動建第 1 版並設為同步版本。同步版本的印件項目就是需求單的印件項目，雙向同步。業務可開新版本、改選同步版本、刪除非同步版本，在議價中下載方案報價單給客戶比較。成交時選定客戶要的版本，系統先切為同步版本再成交，只有該版本轉入訂單。

### 守恆

| 量 | 等式 | 上升方向 | 下降方向 |
|----|------|---------|---------|
| 需求單未稅金額 | 需求單.未稅金額 = 同步版本.未稅金額 = sum(同步版本 印件項目.小計) | 加項目、調高單價或數量、改選金額較高的版本 | 刪項目、調低單價或數量、改選金額較低的版本 |
| 成交轉入金額 | sum(新印件.小計) = 成交當下同步版本.未稅金額 | 不適用：成交後需求單鎖定 | 不適用：同左 |
| 版本金額 | 報價版本.未稅金額 = sum(該版本 印件項目.小計) | 同第一列，限該版本 | 同第一列，限該版本 |

對照 [[售前]] 參考模型守恆-01（商機金額＝同步報價單項目小計加總）。

### 關鍵決策與否決方案

| 決策 | 否決方案 | 否決理由 |
|------|---------|---------|
| 方案掛在需求單下的報價版本 | 另開需求單承載另一套方案 | 同案多張需求單，成交後其他張要標流失，流失統計失真 |
| 標案比價改走報價版本 | 保留訂單層改單價逐份產出 | 比價發生在成交前，不該先建訂單 |
| 每張需求單至少一版 | 版本選用 | Miles 拍板（grill Q3-1），需求單印件項目永遠對應一個版本 |
| 不設停止同步 | 照 Salesforce 可停止同步 | 停止後需求單印件項目不屬任何版本，成交時無預選（grill Q5） |
| 成交選非同步版本時先切同步 | 允許需求單金額與成交金額不一致 | 需求單金額要等於成交金額（grill Q3-2） |
| 不設主要版本 | 照 Salesforce CPQ 另設主要報價單 | 同步版本已承擔，避免兩個標記 |
| 版本只計印件金額 | 照 Salesforce 報價單加折扣、運費 | 公司規則折扣只記在訂單（grill Q8） |
| 方案報價單不經主管核可 | 方案報價單也核可 | 需求單階段不設審核；核可只管訂單階段的報價單（grill Q4） |
| 編輯版本、改選同步併入編輯需求單 | 另立操作 | [[規範 - 實體]] § 三：執行者相同不另立（grill Q12） |
| 新版由業務選來源版本 | 一律從同步版本帶入；空白新版 | 客戶常在某套非同步方案上再改（grill Q13） |
| 評估完成後不再由系統檢查成本 | 進入議價、下載方案報價單、成交都檢查成本已填 | Miles 拍板由業務自己注意（grill Q15）；系統只在送印務評估與評估完成檢查全部版本 |
| 改數量或規格後成本由業務判斷 | 改數量時清空成本估算強制重估 | Miles 拍板全由業務判斷（grill Q16），與 [[數量異動不提醒單價]] 一致 |
| 刪除報價版本為軟刪除 | 硬刪除連同方案報價單（原 P7）；已下載過的版本不能刪 | 客戶可能拿已給出的方案報價單回頭主張價格，要查得到（grill Q17） |
| 印件項目可為零筆 | 每版至少一筆 | 有的訂單不會有印件（grill Q18） |
| 新版帶入參考附件 | 新版不帶附件，業務重傳 | 印務主管估價要看稿件，成交時附件轉入訂單其他附件（grill Q19） |
| 評估期間開版或改選同步不發通知 | 系統自動在 Slack 討論串通知 | 沿用 Slack 只在進入待評估成本時通知的既有約束，業務手動提及（grill Q21） |
| 已刪除版本不還原，可當來源開新版 | 新增還原操作；還原屬實作規格不定義 | 帶回內容即可，不必多一個操作（grill Q22） |
| 議價中新項目沒成本走重新評估 | 開放議價中直接填成本 | 維持議價中改成本要重評的既有規則（grill Q6） |
