# 規劃單：經驗傳承（訂單結案紀錄、印件結案紀錄與留存資訊）

- 分級：結構性（移除訂單對訂單的複製來源關聯；新增印件與活動紀錄關聯）。
- 盤點：`precheck.md`；拍板紀錄：`grill.md`。

## Problem Statement

公司做完一筆訂單後，洽談過程、規格注意事項、審稿與製程的眉角，只留在承辦人腦中或散落在備註。下一次同客戶、同款產品回頭時，接手的人查不到上次的經驗。公司收存的成品樣本放在哪、有沒有拍攝留作實績，也沒有地方記。

現行正本的缺口：

- [[訂單]] 的備註分「內部作業組」與「客戶條款組」，兩組都是訂單進行中的作業說明，不是事後彙整的經驗。
- [[印件]] 沒有任何欄位記成品樣本與留存。
- [[訂單]] 有「訂單複製來源」欄，與活動紀錄的複製紀錄重複，Miles 指示拿掉。

來源是公司測試回饋 L1 #11。

## Solution

在訂單與印件兩層各加一則「結案紀錄」，印件另加樣品與留存資訊各欄。這些欄位不看訂單狀態，任何時間都能寫。複製訂單或印件時不帶入。拿掉訂單複製來源欄，複製來路只記在活動紀錄。

## User Stories

| 編號 | 故事 | 情境類別 |
|------|------|---------|
| US-1 | 身為接單業務，我要在訂單上記下整筆訂單的洽談過程與執行注意重點，讓下次接手的人查得到 | 主情境 |
| US-2 | 身為接單業務，我要在每件印件記下審稿與製程規格的注意事項，讓同款回頭時照做 | 主情境 |
| US-3 | 身為負責審稿人員，我要在負責的印件記下審稿注意事項 | 系統內邊界 |

| US-5 | 身為業務，我要記下放樣品櫃的樣品位置、編號、數量，以及公司另外留下的成品的留存狀態、分類與數量 | 主情境 |
| US-6 | 身為業務，我要標記成品的拍攝等級；客戶不同意公開某一件時，記在留存備註 | 系統內邊界 |
| US-7 | 身為業務，訂單已取消或已完成後，我仍要回頭補記結案紀錄 | 系統內邊界 |
| US-8 | 身為業務，印件因打樣稿件問題被棄用重建時，新印件從空白開始，原印件的紀錄經衍生來源印件回看 | 系統內邊界 |
| US-9 | 身為業務，複製訂單時，新訂單的結案紀錄與留存資訊從初始值開始；查來源訂單看活動紀錄 | 系統內邊界 |

## Implementation Decisions

### 本體

| 項目 | 內容 | 正本卡 |
|------|------|-------|
| 訂單結案紀錄 | 訂單上的單一多行文字欄，另立「結案紀錄」段，不歸兩組備註；由 [[訂單]] OP-ORD-002 編輯訂單填；不看訂單狀態 | [[訂單]] |
| 印件結案紀錄與留存資訊 | 印件結案紀錄、樣品位置、樣品編號、樣品數量、成品留存狀態、留存分類、留存數量、留存備註、拍攝等級；由新操作 [[印件]] OP-PI-027 維護印件結案紀錄與留存資訊填 | [[印件]] |
| 成品留存狀態 | 新增，印件上的單選欄：待留存／已留存／不留存／已清除；印件建立時為待留存；任意切換、不設把關；不開狀態機卡（理由寫在 [[印件]] 段首） | [[印件]]、[[ERP 詞彙表]] |
| 移除訂單複製來源 | 刪 [[訂單]] 訂單複製來源欄與「訂單與訂單（複製建單的來源訂單）」關聯；複製來路只記在訂單活動紀錄 | [[訂單]]、[[ERP 資料結構總覽]]、[[訂單領域資料結構總覽]]、[[訂單複製建單]] |
| 複製 | 新欄位列入印件複製規則的歷程與產出類，複製時回到初始值 | [[印件複製規則]] |
| 終態例外 | 訂單終態時印件欄位唯讀、已取消時訂單資訊唯讀，兩條都排除結案紀錄與留存資訊 | [[訂單印件規格維護]]、[[訂單資訊分區編輯]]、[[線下接單流程群組]] |
| 完成過程 | 新情境卡 | [[結案紀錄與留存資訊維護]] |

### 流程與活動

| 步 | 執行角色 | 活動 | 完成判準 |
|----|---------|------|---------|
| 記訂單結案紀錄 | 業務、諮詢（自己負責） | [[訂單審核活動清單]] ACT-APV-032 | 訂單結案紀錄為新值；訂單活動紀錄留前後對照 |
| 同上，代理或協助 | 被分享（編輯）者；業務主管、訂單管理人、印務主管、印務、審稿主管、Supervisor（全公司） | ACT-APV-033、ACT-APV-034 | 同上 |
| 記印件結案紀錄與留存資訊 | 業務、諮詢（自己負責） | ACT-APV-035 | 被改各欄為新值；印件活動紀錄留前後對照 |
| 同上，代理或協助 | 被分享（編輯）者；全公司六角色 | ACT-APV-036、ACT-APV-037 | 同上 |
| 同上，審稿 | 審稿人員（負責審稿的印件） | ACT-APV-038 | 同上 |

- 經手者在訂單詳情或印件詳情看得到這些欄位，不需另跑報表（3-2）。
- 沒有上游觸發：這是事後補記，由經手人自行發起（3-4）。

### 邊界完整性

| 實體 | 建立 | 修改 | 作廢 | 查詢 |
|------|------|------|------|------|
| 訂單（結案紀錄欄） | 訂單建立時為空 | OP-ORD-002 編輯訂單，任何狀態 | 不適用：欄位隨訂單存在，訂單刪除或取消不另處理欄位 | 訂單詳情 |
| 印件（新欄位） | 印件建立時為空，成品留存狀態為待留存 | OP-PI-027，任何狀態含已棄用 | 不適用：欄位隨印件增刪（P6） | 印件詳情 |
| 活動紀錄（印件） | 系統於 OP-PI-027 等動作寫入 | 不適用：活動紀錄只增不改 | 不適用：同上 | 印件詳情 |
| 活動紀錄（訂單） | 系統於 OP-ORD-002 改訂單結案紀錄、OP-ORD-008 複製訂單（來源與新訂單各一筆）等動作寫入 | 不適用：活動紀錄只增不改 | 不適用：同上 | 訂單詳情；複製來路只記在這裡 |
| 訂單（訂單複製來源欄） | 不適用：本案刪除此欄 | 不適用：同左 | 刪除欄位與「訂單與訂單（複製建單的來源訂單）」關聯；既有值不再顯示，複製來路改由訂單活動紀錄承載 | 不適用：同左 |

| 狀態 | 進入路徑 | 離開路徑 |
|------|---------|---------|
| 成品留存狀態四值 | 印件建立時預設待留存；OP-PI-027 改為任一值 | OP-PI-027 改為其他任一值；不開狀態機，不設轉換條件 |
| 訂單狀態、印件審稿狀態、印件印製狀態 | 不適用：本案不動 | 不適用：本案不動 |

### 守恆

| 量 | 等式 | 說明 |
|----|------|------|
| 印件數量（購買、完工、出貨） | 不受影響 | 樣品數量與留存數量只作紀錄，不扣可出貨額度，與 [[成品庫存]] 無關（[[印件]] 範圍外段） |
| 樣品數量、留存數量 | 不構成守恆量：沒有進出帳，只是現場收存的登記 | [[訂單管理]] 參考模型卡守恆量段同樣沒有出處 |

### 管理指標

本案不新增指標。既有指標（[[生產績效指標]] 各項、利潤率、交期類）的來源欄位都不在本案改動範圍，仍成立。

### 關鍵決策與否決方案

| 決策 | 否決方案 | 否決理由 |
|------|---------|---------|
| 成品留存狀態只當單選欄位 | 開「印件留存狀態」狀態機卡 | Miles 拍板先讓功能可以記錄，不設轉換把關（grill Q1） |
| 訂單結案紀錄併入編輯訂單 | 另立「維護訂單結案紀錄」操作 | [[規範 - 實體]] § 三：執行者相同不另立操作 |
| 任何時間可寫 | 審核通過後才可寫 | Miles 拍板先不看狀態，縮限另議（grill Q3、ORD-065） |
| 維持「樣品」用詞 | 改名「留樣」 | Miles 拍板（grill Q4）；欄位段首寫明與打樣樣品不同 |
| 拿掉訂單複製來源欄 | 保留欄位與活動紀錄並存 | 同一事實兩處記，Miles 指示拿掉（P8） |
| 印件層另立 OP-PI-027 | 併入 OP-PI-001 編輯印件 | 執行者多了負責審稿人員，與一般編輯不同（[[規範 - 實體]] § 三；[[印件]] 操作段說明） |
| 兩則結案紀錄都是單一多行文字欄 | 多筆條目（每則記寫入者與時間） | 寫入者與時間已由活動紀錄的前後對照承載，不另建子表（grill Q5-3） |
| 客戶同意公開沿用訂單層授權分享 | 印件層新增拍攝許可欄 | Miles 拍板不新增（grill P3、Q5-5）；單件不同意寫在留存備註 |
| 樣品與留存兩批各自獨立，成品留存狀態只管留存那批 | 樣品是留存的一部分；合併成一個數量欄 | Miles 拍板（grill Q8）：放樣品櫃供展示或對樣的成品，與公司另外留下的成品是兩批實物 |

## Testing Decisions

| 編號 | 驗收條目 | 對應 |
|------|---------|------|
| T-1 | 訂單在草稿、審核通過、訂單完成、已取消各狀態，業務都能改訂單結案紀錄，活動紀錄留前後對照 | US-1、US-7 |
| T-2 | 印件已棄用時仍能改印件結案紀錄與留存資訊 | US-8 |
| T-3 | 新建印件的成品留存狀態為待留存；四值可互相切換 | US-5 |
| T-4 | 負責審稿人員能改自己負責印件的欄位，不能改其他印件 | US-3 |
| T-5 | 複製訂單後，新訂單與新印件的新欄位為初始值；兩張訂單活動紀錄各寫一筆複製紀錄；訂單上沒有複製來源欄 | US-9 |
| T-6 | 打樣稿件問題重建的新印件，新欄位為初始值，經衍生來源印件可回到原印件 | US-8 |
| T-7 | 樣品數量、留存數量填任意值，不影響可出貨額度 | 守恆 |

情境目錄與測試在實作階段補，依 erp repo 流程。

## Out of Scope

- Prototype 實作與介面（訂單頁籤、印件詳情的版型）。
- 留存分類值域（[[PI-011-印件留存分類的值域]]）。
- 可編輯時點縮限（[[ORD-065-結案紀錄與留存資訊可編輯時點是否縮限]]）。
- 下層角色看不看得到結案紀錄頁籤（既有 XM-016）。
- 成品庫存、實物樣品的進出管理。
