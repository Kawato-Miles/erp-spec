## 二、本次 grill 拍板（Miles 2026-11-05）

| 編號 | 題目 | 拍板 |
|------|------|------|
| Q1 | 成品留存狀態要不要開狀態機卡 | 不開；只當印件上的單選欄位，四值可任意切換、不設把關。不開卡理由寫在印件卡 |
| Q2 | 誰可編輯 | 另立操作；業務、印務、審稿都可：訂單層比照編輯訂單的執行者；印件層再加工單負責印務與負責審稿人員 |
| Q3 | 適用訂單與時點 | 線下單、線上單、諮詢訂單都適用（諮詢訂單沒有印件，只有訂單結案紀錄）；訂單結案紀錄與印件新欄位都不看訂單狀態，任何時間都可寫，含訂單完成與已取消。取代交接時「起點是訂單審核通過後」。之後是否縮限時點另開 OQ |
| Q4 | 「樣品」同詞兩義 | 維持「樣品」；欄位定義寫明是公司收存的成品樣本，與打樣印件做出的樣品不同 |
| Q5-2 | 名稱 | 維持「結案紀錄」，定義寫明與訂單狀態無關 |
| Q5-3 | 形態 | 兩個結案紀錄都是單一多行文字欄；印件結案紀錄是印件上的欄位 |
| Q5-4 | 訂單上的位置 | 訂單結案紀錄另立一段，不歸內部作業組、客戶條款組 |
| Q5-5 | 拍攝等級與授權分享 | 拍攝等級在印件層；客戶同意沿用訂單層授權分享；單件不同意寫在留存備註 |
| Q5-6 | 已棄用印件 | 仍可編輯 |
| Q5-7 | 稿件問題重建 | 新印件不帶入，經衍生來源印件連結回看 |
| Q5-8 | 數量 | 留存數量、樣品數量的單位同印件單位；不扣可出貨額度、不設上限、與成品庫存無關 |
| Q5-9 | 樣品編號 | 手填 |
| Q5-10 | 成品留存狀態初始值 | 新印件預設待留存 |
| Q5-11 | 複製 | 新欄位回到初始值（空白；成品留存狀態為待留存） |
| Q5-12 | 活動紀錄 | 編輯要記；總覽卡補上印件與活動紀錄的關聯 |
| Q5-13 | 可見範圍 | 結案紀錄頁籤跟訂單詳情；下層角色可見性掛既有 XM-016 |

| Q6 | 訂單結案紀錄的操作粒度（落卡後矛盾呈報） | 依 [[規範 - 實體]] § 三併入編輯訂單，活動列另列；不改規範 |
| Q7 | 印件層「印務依工單負責人」活動列 | 刪除；全公司列已含印務 |
