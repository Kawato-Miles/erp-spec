# 20：Anthropic 對現行模型的環境設定建議

Type: research
Status: resolved

## Question

Anthropic 官方對現行模型與 Claude Code 的環境設定有哪些建議：AGENTS.md 或 CLAUDE.md 寫什麼與多長、skill 怎麼寫、子代理、hook、記憶、長任務與跨工作階段接續？
新模型相對舊模型，官方建議改變哪些寫法？

## Answer

全文在 `research/20-anthropic-setup-guidance.md`，檔頭有主對話的抽查。官方有針對現行模型（Fable 5.2）的提示指南，主對話已讀全文。

- 指令檔只放模型讀不到的事，每檔目標少於 200 行。它是脈絡不是強制；零例外的規則改用 hook 或權限規則。
- 規則被忽略時加強語氣沒有用。通常是檔案太長，或那條規則該寫成 hook。
- Fable 5.2 照字面遵循指令。累積的「絕不」類告誡會讓它多要核准或不做例行工作。官方建議：刪掉理由已不成立的告誡；絕對規則改寫成寫明範圍與理由；記憶與備註也要刪減。
- 硬性寫作限制會讓文字斷裂。官方同時建議報告大致採 STE100 風格。現行輸出風格檔的 30 字、25 字上限屬於硬性限制。
- 自動記憶每次只載入索引檔前 200 行或 25KB。現行索引檔 28,110 位元組，尾端約二十列啟動時不載入。
- 子代理耗用量大。檢視 skill 與代理定義裡叫模型委派的句子。
- 長任務：狀態存檔案與 git，新工作階段從檔案讀回進度，並行工作用工作樹隔離。
- 官方建議的遷移順序：先定努力度；讀過並刪減帶過來的指令、skill、記憶、備註；跑最長的任務觀察；再逐項套用並量測。
- 未查證 12 項，含 Haiku 5.5 指南全文、多檔合計上限、官方對 CHANGELOG 與重複規則的說法。
